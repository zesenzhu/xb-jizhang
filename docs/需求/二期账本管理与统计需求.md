# 二期账本管理与统计需求（评审稿）

## 1. 文档目的

本文定义第二期的底部导航、当前账本切换与管理、共享账本协作、统计页面和相关业务数据，作为产品评审和下游 UI、后台、接口设计的依据。本文不规定代码模块、数据库表或接口路径。

一期收入/支出记账和账单流水能力继续保留。**二期仍不包含转账、资产、负债和净资产功能。**

## 2. 背景与目标

### 2.1 背景

- 用户可能拥有多个个人账本，也可能加入多个共享账本，需要明确当前正在查看哪一本。
- 账单首页应聚焦当前账本，不把多个账本的数据混合展示；账本切换与管理需要有清晰入口。
- 多人共享需要让 Owner 管理成员和邀请，同时让 Editor、Viewer 按各自权限参与。
- 用户需要从收入、支出、分类和时间汇总等角度理解账本数据；当前没有资产和负债数据，统计不能展示相关趋势。

### 2.2 二期目标

- 底部主导航固定为“账本、统计、我的”三个入口。
- 账单页只显示当前选中账本；当前账本名称右侧提供切换入口。
- 用户能在“我的账本”中查询、创建、编辑、复制和切换个人/共享账本。
- Owner 能邀请和管理共享账本成员；成员能查看自己的角色和共享账本信息。
- 统计页按周、月、年、全部或自定义范围展示收入、支出、结余、趋势、分类和账单汇总。
- 所有统计都严格限定在当前账本和当前时间范围内，不混用其他账本数据。

## 3. 用户和账本类型

### 3.1 用户角色

| 身份 | 二期能力 |
| --- | --- |
| 普通用户 | 管理自己拥有的账本、切换可访问账本、查看统计和个人页面。 |
| `OWNER` | 编辑所属账本，管理邀请和成员，修改成员角色，移除成员，转移 Owner。 |
| `EDITOR` | 查看共享账本、账单和统计；账单新增/编辑/删除规则沿用一期确认后的账单需求。不能管理账本成员。 |
| `VIEWER` | 只读查看共享账本、账单和统计；不能记账或管理成员。 |

账本角色是账本范围内的权限，不是平台管理员角色。账单具体删除权限以一期账单需求最终批准版为准；本期不重新定义账单编辑权限。

### 3.2 账本类型

- **个人账本**：默认只由创建者作为 Owner 使用，不开放成员邀请。
- **共享账本**：由 Owner 管理，允许通过邀请加入 Editor 或 Viewer。
- 账本创建时选择类型；创建后不允许直接将个人账本转换为共享账本，或将共享账本转换为个人账本。
- 用户可以同时拥有多个个人账本，也可以加入多个共享账本。

## 4. 二期范围

### 4.1 本期包含

- 底部导航改为“账本、统计、我的”。
- 账本首页显示当前账本的概览和账单，不显示跨账本聚合列表。
- 在当前账本名称右侧提供切换入口，进入“我的账本”管理页。
- 个人账本和共享账本的创建、查询、编辑、复制、切换，以及空账本删除。
- 本期不提供账本归档和恢复；有账单的账本不能删除。
- 注册后自动创建“我的账本”；新用户不得进入没有可用账本的状态。
- 账本详情设置：编辑名称/图标、查看和管理成员、进入分类管理、设置币种、复制和删除空账本。
- 共享账本邀请、接受/拒绝邀请、撤销邀请、成员列表、角色修改、移除成员、主动退出和 Owner 转移。
- 统计时间维度：周、月、年、全部、自定义范围。
- 统计内容：收支统计、收支趋势、分类统计和账单汇总。
- 统计图表与汇总行可下钻到账单页，并保留对应账本、时间范围和分类条件。

### 4.2 本期不包含

- 转账记账及转账统计。
- 资产、负债、净资产趋势和资产账户总览。
- 预算、预算超支提醒、定期账单、账单分摊。
- 多币种折算、汇率维护、跨币种账本。
- 实时共同编辑、账本内聊天、成员活动动态或推送通知中心。
- 平台管理员代替账本 Owner 修改普通用户账本或账单。
- 账本归档和恢复。

## 5. 全局导航

### 5.1 底部主导航

底部只保留三个入口：

| 导航项 | 用途 |
| --- | --- |
| 账本 | 查看当前账本流水和收支概览。 |
| 统计 | 查看当前账本在选定时间范围内的统计。 |
| 我的 | 查看个人资料、设置和当前账号相关入口。 |

- 移除底部的“明细”和独立“记账”导航项；明细仍由账本页流水承载。
- 移除“资产”导航项。二期没有资产功能，不显示资产页面或资产趋势入口。
- 记账能力继续保留，但入口只沿用账本页右下角的“+”；统计页、我的页和账本管理页不显示记账按钮。
- 进入“我的账本”、账本设置和成员管理等二级页面时隐藏底部主导航，使用页面内返回操作回到来源页。
- 切换主导航不会改变当前账本；账本切换后账本页和统计页使用新的当前账本。

### 5.2 当前账本状态

- 当前账本是用户最近一次主动选择的可访问账本；首次使用时为系统自动创建的“我的账本”。
- 当前账本选择按当前用户保存，不影响其他共享成员的当前账本选择。
- 用户失去访问权限或离开共享账本后，切换到该用户其他可访问账本；如果没有其他账本，则引导创建或加入账本。
- 任一页面切换账本后，旧账本的统计、流水和成员信息不得短暂残留。

## 6. 账本首页

### 6.1 页面结构

1. 顶部显示当前账本名称，切换按钮紧邻名称右侧；标题区域不展示所有账本名称列表。
2. 继续显示当前账本的收支概览和按日分组的账单流水，遵循《一期账本与记账需求》。
3. 右下角保留“+”记账入口，仅对有新增账单权限的成员显示。
4. 当前账本切换按钮点击后进入完整的“我的账本”管理页，不在首页展开全部账本列表。

### 6.2 切换操作

- 点击当前账本名称右侧的切换按钮，进入“我的账本”。
- 当前账本卡片有明确的选中标识；点击其他可访问的账本卡片后立即切换，并返回账本首页。
- 切换完成后，首页概览、账单列表和统计查询上下文更新为新账本。
- Viewer 可以切换和查看共享账本，但不能看到创建、编辑、删除、邀请等管理操作。

## 7. 我的账本与账本管理

### 7.1 管理页布局

管理页标题为“我的账本”，顶部提供新建“+”和更多菜单。账本按“个人账本”和“共享账本”分组。

每张账本卡片显示：

- 账本图标和名称；
- 个人/共享类型；
- 当前选中标记；
- 共享账本成员数和当前用户角色；
- Owner 可见账本操作菜单。

账本卡片主体点击即切换到该账本并返回账本首页；操作菜单与切换点击区域分开，避免误切换。

### 7.2 自动创建和默认账本

- 新用户注册完成后自动创建一个名称为“我的账本”的个人账本，并将其设为当前账本。
- 已有用户升级到二期时不重复创建个人账本；沿用现有可访问账本和当前账本选择。
- 用户可以将一个可访问的账本设为自己的默认账本；默认账本用于新会话或未保存当前选择时的回退。
- 系统生成的“我的账本”可以改名；名称不再是固定只读文本。

### 7.3 创建账本

- 从管理页点击“+”打开创建流程。
- 必填账本名称；类型为个人账本或共享账本；默认币种为人民币 CNY；账本时区默认 `Asia/Shanghai`；图标为可选项。
- 账本时区使用 IANA 时区标识；不接受无法识别或不在服务端支持范围内的时区。
- 创建个人账本后直接成为 Owner，并返回管理页；用户可以选择将它切换为当前账本。
- 创建共享账本后创建者成为 Owner，完成创建后进入成员/邀请管理，可选择稍后邀请。
- 名称去除首尾空格后不能为空；同一用户可有同名账本，但列表必须能通过类型和图标区分。
- 创建失败时保留已填写内容，不生成半成品账本。

### 7.4 编辑账本

- Owner 可编辑账本名称、图标、颜色和时区；Editor、Viewer 只能查看账本信息。
- 账本类型创建后不可编辑。
- 币种可以在账本设置中查看；账本已经存在账单后币种只读，避免历史金额解释发生改变。
- 若账本尚无账单，Owner 可以修改币种；修改前需要二次确认，并说明金额输入和展示单位会改变。
- 修改时区不会修改账单原始时间，但会改变统计按自然日、月和年的分组边界；修改前需要明确提示这一影响。
- 成员角色、账单和账户数据不属于账本资料编辑字段。

### 7.5 复制账本

- Owner 可以复制自己管理的账本；非 Owner 不显示复制操作。
- 复制结果创建为一个新的个人账本或共享账本，由操作者明确选择类型和名称。
- 复制账本只复制账本基本展示设置和分类配置，不复制账单、成员、邀请、账户余额或统计数据。
- 复制完成后操作者成为新账本 Owner；共享账本成员需要重新邀请。

### 7.6 删除账本

- 本期不提供账本归档和恢复。
- Owner 仅可永久删除没有任何账单（包括软删除账单）、没有其他活跃成员且没有待处理邀请的空账本；删除前明确提示不可恢复。
- 有账单的账本不能删除，继续保留在账本列表中供成员查看和使用；后续版本再评估归档能力。
- 用户不能删除自己最后一本可用账本；必须先创建或加入另一本账本。
- 共享空账本删除前说明该账本及其配置将被永久删除、无法恢复，并要求二次确认。

### 7.7 账本设置入口

账本详情设置参考用户提供的账本详情截图，至少提供：

- 编辑账本；
- 成员与邀请管理（仅共享账本显示）；
- 分类管理；
- 账本币种；
- 复制账本；
- 删除空账本（仅 Owner 且满足删除条件时显示）。

无权管理的成员可以查看账本名称、类型、币种和成员角色，但不显示管理操作。

## 8. 共享账本与成员协作

### 8.1 邀请成员

- 共享账本 Owner 可以从账本设置进入成员管理，再创建邀请。
- 个人账本不显示邀请入口；服务端也必须拒绝针对个人账本的邀请请求。
- 邀请目标使用邮箱；邀请角色只能选择 `EDITOR` 或 `VIEWER`，不能通过邀请授予 `OWNER`。
- 邀请有效期 72 小时；邮箱规范化、一次性 Token、撤销和重新加入规则沿用现有账本成员领域约定。
- 邀请发起后显示目标邮箱、授予角色、发起时间、过期时间和待处理状态。
- Owner 可以复制邀请链接或撤销待处理邀请；需要重新邀请时撤销旧邀请并创建新邀请。
- 被邀请人登录后，只有其已绑定且匹配目标邮箱时才能接受邀请；接受或拒绝后状态即时更新。
- 过期、撤销或已处理的邀请不能再次接受；`LEFT`、`REMOVED` 成员必须通过新邀请重新加入并复用原成员关系。

### 8.2 成员管理

- 所有活跃成员可以查看共享账本的活跃成员名单、昵称、头像、角色和加入时间。
- 只有 Owner 可以修改 Editor/Viewer 角色、移除成员、撤销邀请和转移 Owner。
- Owner 转移给一名活跃成员后，新成员成为 Owner，原 Owner 降为 Editor；账本始终至少保留一名 Owner。
- Owner 不能移除自己；需要离开时先转移 Owner。
- Editor 和 Viewer 可以主动退出共享账本；最后一名 Owner 不能退出。
- 个人账本只有创建者 Owner，Owner 不能主动退出个人账本；如需停用，应保留账本或先删除满足条件的空账本。
- 移除或退出后，成员立即失去账本的账单、统计、账户和分类访问权限。
- 成员角色变化后，前端刷新权限状态；失去写权限时隐藏记账和管理操作。

### 8.3 账本可见性和访问边界

- 用户的“我的账本”列表显示其活跃成员关系可访问的个人/共享账本。
- 共享账本的账单和统计只基于当前账本；私人账户可见性仍遵循账户权限规则。
- 账本 Owner 的管理权限不能扩大到平台管理员权限；平台管理员身份不进入普通用户的成员列表。

## 9. 统计页面

### 9.1 页面结构

统计页顶部提供时间维度选择，下面按顺序展示：

1. 收支统计概览；
2. 收支趋势图；
3. 分类统计；
4. 当前时间范围内的账单汇总。

统计页不显示总资产、总负债、净资产趋势，也不出现依赖尚未建设的资产数据。

### 9.2 时间维度和日期导航

统计页顶部使用分段 Tabs：`周`、`月`、`年`、`全部`、`范围`。默认选中“月”，显示当前自然月。

| 维度 | 时间范围 | 趋势/汇总默认分组 |
| --- | --- | --- |
| 周 | 账本时区下周一至周日 | 按日 |
| 月 | 当前或选择的自然月 | 按日 |
| 年 | 当前或选择的自然年 | 按月 |
| 全部 | 从账本首笔账单至今 | 按年 |
| 范围 | 用户选择的起止日期，首尾日期均包含 | 根据范围自动按日、月或年分组，可手动切换合适粒度 |

- Tabs 下方显示当前时间范围，左右箭头切换上一/下一周、月或年。
- 全部范围不显示左右翻页；范围模式通过日期选择器修改起止日期。
- 不允许导航到未来统计周期；未来箭头禁用。
- 切换时间维度或范围时，所有概览、图表、分类和汇总同时刷新，不保留上一个范围的旧数据。
- 当前账本切换后，统计页使用新账本的当前时间维度和范围。

### 9.3 收支统计

概览显示所选时间范围内的：

- 总支出；
- 总收入；
- 结余（总收入减总支出）；
- 日均支出（有效自然日内的支出均值）。

点击总支出或总收入可进入账单页并应用当前账本、时间范围和对应类型筛选。结余不是账户余额、净资产或资金存量。

### 9.4 收支趋势图

- 标题为“收支趋势”或同义标题，默认展示支出趋势。
- 图表下方提供 `支出`、`收入`、`结余` 三项分段 Tabs。
- 支出和收入按所选时间粒度展示各周期金额；结余按每个周期“收入减支出”展示，不表示累计资产余额。
- 点击柱/点显示对应日期或月份及金额；点击详情入口跳到账单页并带入该周期范围和当前图表类型。
- 无数据时显示零值空状态，不绘制虚假的趋势线。
- 不展示资产、负债、净资产或账户余额走势。

### 9.5 分类统计

- 模块标题为“分类统计”；默认显示支出分类。
- 提供支出/收入切换；切换后分类图、总额、占比和列表全部按所选类型重算。
- 环形图中心显示所选类型总额；扇区按分类金额占比绘制。
- 列表显示分类图标、名称、占比、金额和账单笔数；点选分类进入该分类的账单列表。
- 支持一级分类和二级分类层级切换；选择一级分类可查看二级分布，选择二级分类可查看其账单。
- 支持“金额/占比”排序，以及可选的“显示环比金额”辅助信息；环比使用上一段等长周期。
- 无分类账单单独归入“未分类”，但一期创建规则要求收入/支出选择分类；仅用于兼容历史或异常数据。

### 9.6 账单汇总

- 汇总仅包含当前账本和当前时间范围，不查询范围以外数据。
- 表格至少显示日期/周期、支出、收入和结余；顶部提供区间合计和日均值。
- 周/月默认按日列出；年按月列出；全部按年列出；自定义范围按范围大小自动选择日、月或年。
- 自定义范围的粒度可在不超出所选范围的前提下切换；小范围不能切换为导致单行数据含义不清的粒度。
- 点击某一行进入账单页，日期筛选精确对应该行周期；点击总计使用完整选定范围。
- 结余始终按该行期间的收入减支出计算，不做资产余额累计。
- 金额为零的周期可显示为零值行；默认不隐藏时间上连续的空周期，以便对照周期。

### 9.7 统计过滤和数据口径

- 所有统计只包含当前账本、未删除的收入和支出账单。
- 私人账户账单按当前成员的账户可见性过滤；不可见账单不能出现在汇总或分类总额中。
- 统计日期边界按账本时区计算，筛选起止日期均包含。
- 修改、删除、恢复账单或切换账本后，统计重新读取并呈现一致结果。
- 统计页按角色只读；Viewer 可以查看自己有权查看的统计，但不能从统计页触发记账或账本管理操作。

## 10. “我的”页面

- 底部“我的”进入个人中心，显示头像、昵称和账号信息。
- 至少提供个人资料、账号与安全、我的邀请、帮助与关于入口。
- “我的账本”不必在该页重复列出全部账本；账本切换和管理的主要入口是账本首页当前账本名称右侧按钮。
- 个人资料和账号安全不属于本期重点改造，沿用现有能力；本期不新增平台管理员入口。

## 11. 产品数据规则

### 11.1 账本

账本产品数据至少包含：账本标识、名称、个人/共享类型、币种、IANA 时区、图标、颜色、创建人和创建/修改时间。当前账本和默认账本是当前用户的选择，不等同于账本的 Owner 身份。

### 11.2 成员与邀请

- 成员关系包含账本、用户、角色、状态、加入时间。
- 邀请包含目标邮箱、角色、状态、过期时间、发起人和处理时间。
- 邀请 Token 是一次性凭证；邀请管理页不显示完整历史 Token。
- 成员离开或被移除后保留关系状态用于防止重复创建和支持重新加入。

### 11.3 统计口径

- 总支出 = 当前范围内未删除的支出合计。
- 总收入 = 当前范围内未删除的收入合计。
- 结余 = 总收入 - 总支出，可为负数。
- 日均支出 = 总支出 / 当前范围内存在当前用户可见账单的有效自然日数；无任何有效日时为零。
- 分类占比 = 当前分类金额 / 当前类型总额；总额为零时所有占比显示为零。
- 二期不新增资产、负债、净资产或转账金额数据。

## 12. 异常和空状态

- **没有其他账本**：管理页展示“新建账本”操作；个人默认账本不可被删除为零账本状态。
- **无权管理**：隐藏 Owner 操作；若权限在页面打开后变化，提交时提示权限已变化并刷新成员状态。
- **最后一本账本**：删除前提示先新建或加入其他账本，不允许操作后进入无账本状态。
- **账本含账单**：不显示删除操作；用户尝试通过其他入口删除时拒绝请求并说明含账单的账本不能删除。
- **账本仅含软删除账单**：仍视为含账单，不允许永久删除。
- **没有成员**：共享账本显示邀请入口和成员空状态。
- **没有待处理邀请**：邀请列表展示空状态和重新邀请入口。
- **统计无数据**：显示零值和无数据图表状态；不伪造分类或走势。
- **统计加载失败**：保留已选时间范围，提供重试；不得继续展示其他时间范围或账本的旧数据。
- **邀请过期/撤销/邮箱不匹配**：显示明确原因，不改变成员关系；Owner 可重新发起邀请。

## 13. 验收标准

1. **给定**新用户完成注册，**当**首次进入账本，**则**系统已创建“我的账本”并将其选为当前账本。
2. **给定**已有用户升级到二期，**当**进入账本管理，**则**沿用其已有账本，不额外创建重复个人账本。
3. **给定**用户位于账本首页，**当**查看顶部，**则**只显示当前账本名称及其右侧切换按钮，不显示全部账本列表。
4. **给定**用户点击当前账本右侧切换按钮，**当**进入管理页，**则**能看到个人账本、共享账本和当前选中状态；选择其他活跃账本后返回首页并更新所有账单数据。
5. **给定**用户打开底部导航，**当**任一主页面展示完成，**则**只出现账本、统计、我的三个入口；独立明细、记账和资产入口不存在。
6. **给定**用户处于统计页或我的页，**当**浏览页面，**则**不显示账单页右下角记账按钮。
7. **给定**Owner 创建个人或共享账本，**当**名称和类型有效，**则**账本创建成功且创建者成为 Owner；创建失败时没有半成品。
8. **给定**Editor 或 Viewer 打开账本设置，**当**页面展示操作项，**则**不显示编辑、复制、删除或成员管理操作。
9. **给定**账本存在账单，**当**Owner 查看账本设置或尝试删除，**则**不提供删除操作并保留账本及其历史数据；本期没有归档/恢复入口。
10. **给定**用户尝试删除最后一本可用账本，**当**提交操作，**则**系统拒绝并说明需先创建或加入其他账本。
11. **给定**Owner 邀请成员，**当**填写邮箱和 Editor/Viewer 角色，**则**生成 72 小时有效邀请；邮箱不匹配、过期或撤销的邀请不能加入。
12. **给定**Owner 管理共享成员，**当**修改角色、移除成员或转移 Owner，**则**权限即时生效且账本始终至少保留一名 Owner。
13. **给定**用户选中周/月/年/全部/范围任一统计维度，**当**数据加载完成，**则**概览、趋势、分类和账单汇总使用同一账本和同一时间范围。
14. **给定**用户切换趋势图的支出/收入/结余 Tabs，**当**选择变化，**则**图表展示所选范围的周期收支或周期结余，不显示资产/负债数据。
15. **给定**用户点击分类项或账单汇总某个周期，**当**跳转到账本页，**则**账单列表带入当前账本及精确分类/时间范围筛选。
16. **给定**统计范围无账单，**当**页面加载完成，**则**金额显示为零并展示空图表状态，不残留上次统计数据。
