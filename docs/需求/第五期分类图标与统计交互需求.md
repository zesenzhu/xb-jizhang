# 小宝记账第五期分类图标与统计交互需求

## 1. 文档目的

本文定义第五期的分类图标体系和统计图表交互优化需求，作为产品评审、后台接口、前端页面和后续测试的共同依据。

一期的收入/支出记账、二期的账本管理与统计能力继续保留。本期不改变账单金额、账户余额、统计时间范围、账本角色和分类层级规则。

本文只定义用户可见的产品行为、业务规则、数据语义、交互状态和验收口径，不规定具体代码模块、数据库表名或接口路径。技术实现应在本需求确认后补充到对应的技术、API 和前端文档中。

## 2. 背景与问题

### 2.1 分类图标问题

当前分类缺少稳定的视觉识别。分类没有图标时，页面使用分类名称首字和哈希色板作为降级显示，分类在记账面板、账单列表和统计页之间缺少统一的图形表达。

当前分类管理已经支持 Owner 新增、编辑、排序和停用分类，但图标选择仍属于后续能力。第五期需要让内置分类拥有预置图标，并让用户创建的分类可以使用图标库图标或上传图片。

### 2.2 统计图表问题

当前趋势图和环形图可以绘制数据，但点击图形后不能稳定看到对应的具体数据。SVG 内部的 `<title>` 只能提供有限的浏览器原生提示，不适合作为移动端的主要交互。

当前统计页还存在以下问题：

- 趋势图点击回调没有完整连接到统计页面；
- 环形图虽然有点击能力，但没有连接到 Tooltip 或下钻反馈；
- 环形图中心金额的位置依赖覆盖布局，金额较长时可能与环形边界或其他内容重叠；
- 分类数量较多时，环形图扇区过密，难以比较；
- 图表只有峰值文字，缺少足够的尺度信息；
- 分类图表和分类列表没有完整复用分类图标；
- 图表上的金额使用紧凑格式时，用户无法直接确认精确金额。

## 3. 目标与非目标

### 3.1 本期目标

- 为一期默认分类预置稳定、统一的图标；
- 为自定义分类提供图标库选择和图片上传能力；
- 让共享账本中的分类图标对所有活跃成员保持一致；
- 让分类图标在记账、账单、统计和分类管理页面保持一致；
- 让用户点击趋势图或分类图表后立即看到具体金额、占比和账单数量；
- 让 Tooltip 支持移动端点击、桌面端鼠标和键盘操作；
- 优化趋势图和环形图的布局、金额展示、颜色和空状态；
- 保留现有统计下钻能力，并让 Tooltip 提供明确的下钻入口。

### 3.2 本期不包含

- 不调整收入、支出和结余的统计口径；
- 不新增转账、资产、负债、净资产或预算统计；
- 不支持用户按个人账号覆盖共享账本的分类图标；
- 不支持 AI 生成图标；
- 不支持任意文件上传或图标素材市场；
- 第一版不支持任意 SVG 文件上传；
- 不新增统计图导出、分享和打印；
- 不替换统计接口的时间范围和下钻参数规则；
- 不改变分类最多两级、Owner 管理分类和停用代替物理删除的规则。

## 4. 图标库方案

### 4.1 选型结论

用户端系统操作图标继续使用现有的 `lucide-react`。分类图标使用 Tabler Icons 的精选子集。

Tabler 官方仓库当前标注 6,287 个 MIT 图标，包含线框和填充图标，覆盖餐饮、交通、购物、居住、娱乐、教育、医疗和收入等分类场景。Lucide 官方仓库当前标注 1,600+ 个 ISC 图标，已经用于本项目的按钮、导航和系统操作，继续保留可以避免全站 UI 图标迁移。

### 4.2 分类图标使用规则

- 分类图标统一使用 Tabler 的线框风格；
- 图标放在固定尺寸的圆形或圆角方形背景中，背景色来自分类颜色；
- 同一个分类在记账九宫格、账单卡片、分类管理、统计图例和统计列表中使用同一个图标；
- 图标库只展示经过产品筛选的分类图标，不开放全部 6,287 个图标；
- 图标搜索支持中文关键词和英文别名；
- 图标数据保存带命名空间的稳定键，例如 `tabler:tools-kitchen-2`；
- 前端不能根据分类名称自行猜测图标；
- 图标库升级时保留旧键的映射或降级图标，不能因为图标包升级导致历史分类变成空白；
- 图标库的许可证和版权说明保留在项目依赖和发布物中。

### 4.3 默认分类映射

一期默认的 16 个一级分类和 49 个二级分类都必须有预置图标。图标映射由默认分类数据维护，不由客户端硬编码分类名称。

示例映射方向：

| 分类场景 | 图标方向 |
| --- | --- |
| 餐饮 | 餐具、碗、咖啡、汉堡 |
| 交通 | 公交、汽车、地铁、路线 |
| 购物 | 购物车、购物袋、礼物 |
| 服饰 | 衬衫、鞋、眼镜 |
| 居住 | 房屋、家具、灯具 |
| 生活服务 | 工具、剪刀、洗衣 |
| 医疗健康 | 医疗十字、药品、心脏 |
| 教育学习 | 书本、毕业帽、铅笔 |
| 娱乐休闲 | 电影、音乐、游戏、运动 |
| 人情往来 | 礼物、爱心、用户 |
| 工资收入 | 公文包、现金、银行卡 |
| 经营收入 | 商店、建筑、订单 |
| 投资理财 | 趋势、硬币、图表 |
| 报销退款 | 回退、收据、钱包 |

支付宝、微信和银行卡等场景使用通用图标，不在系统默认分类中直接使用品牌 Logo。

## 5. 分类图标产品需求

### 5.1 分类图标数据语义

每个分类需要有一个明确的图标来源：

| 字段语义 | 可选值 | 说明 |
| --- | --- | --- |
| `iconSource` | `NONE` | 使用系统降级图标 |
| `iconSource` | `LIBRARY` | 使用图标库图标 |
| `iconSource` | `IMAGE` | 使用用户上传图片 |
| `iconKey` | 字符串或空 | 图标库稳定键，`LIBRARY` 时必填 |
| `iconAssetId` | ID 或空 | 图片资源标识，`IMAGE` 时必填 |
| `color` | 颜色值或空 | 分类背景色和统计图表颜色 |

`iconSource`、`iconKey` 和 `iconAssetId` 必须保持互斥一致。客户端提交的数据不一致时，服务端拒绝保存，不使用客户端猜测的优先级覆盖错误数据。

### 5.2 内置分类

- 新建账本时，默认分类和默认图标在同一事务中初始化；
- 历史账本补齐默认分类时，只给缺失的默认分类补齐图标；
- 已有分类名称、启停状态和账单关联不被覆盖；
- Owner 可以修改系统默认分类的名称、排序、图标和颜色；
- 系统默认分类不能物理删除；
- 修改系统默认分类图标不改变分类 ID，也不影响历史账单归属；
- 编辑系统分类时提供“恢复默认图标”操作；
- 恢复默认只恢复图标和默认颜色，不恢复分类名称、排序和启用状态。

### 5.3 新建和编辑分类

Owner 打开分类编辑面板时，可以在名称、归属和排序字段之外设置图标。

交互线框：

```text
┌───────────────────────────────────┐
│ ✕              新增分类            │
├───────────────────────────────────┤
│ 名称          [餐饮              ] │
│ 归类          ○ 一级分类           │
│               ○ 归到「生活服务」   │
│ 排序          [0                 ] │
│ 图标          [ 预览 ]             │
│                                   │
│ [图标库]  [上传图片]  [恢复默认]   │
├───────────────────────────────────┤
│ 搜索图标      [餐饮              ] │
│ [餐具] [购物] [交通] [居住]        │
│  [图]    [图]    [图]    [图]      │
│  [图]    [图]    [图]    [图]      │
├───────────────────────────────────┤
│                         [保存]     │
└───────────────────────────────────┘
```

交互规则：

- 默认选中当前分类已有图标；
- 新建默认分类时预选与当前分类类型对应的默认图标；
- 选择图标后立即更新预览，点击保存后才提交分类变更；
- 切换“收入/支出”时，图标搜索结果仍只显示当前可用的图标，但不改变分类类型；
- 点击取消时，未保存的图标选择和临时图片全部丢弃；
- 保存中禁止重复提交，保存失败保留表单内容和图标选择；
- 分类名称、层级、排序和停用规则沿用现有分类需求；
- `EDITOR` 和 `VIEWER` 不显示图标编辑入口，直接访问写接口仍返回权限错误。

### 5.4 上传图片

自定义分类可以使用上传图片作为图标。第一版限制如下：

- 支持 `PNG`、`JPEG`、`WebP`；
- 单张图片最大 `2MB`；
- 建议使用正方形图片；
- 前端提供正方形预览，图片在分类图标容器内使用等比裁切；
- 服务端根据文件头校验真实 MIME 类型和文件大小；
- 不允许通过扩展名伪装文件类型；
- 第一版不允许任意 SVG 文件；
- 图片上传时显示进度、失败状态和重试操作；
- 上传期间关闭编辑面板时，临时图片必须进入清理流程；
- 上传完成但分类保存失败时，临时图片不能长期占用用户配额；
- 图片资源只对有权访问该分类所属账本的成员可见。

图片上传沿用本地 MinIO、线上阿里云 OSS 的对象存储环境，但分类图标资源与账单附件分开管理。分类图标资源至少需要有 `PENDING`、`ATTACHED`、`DELETED` 三种业务状态。

### 5.5 图标展示和降级

分类图标展示尺寸由页面确定，但图标容器必须有稳定尺寸，不能因为图片加载、图标名称或金额变化导致列表跳动。

降级顺序：

1. 图片资源有效时显示上传图片；
2. 图标库键有效时显示图标库图标；
3. 分类有颜色时显示颜色背景和名称首字；
4. 最终使用固定默认图标和中性颜色。

图片加载失败时不能显示破损图片图标，也不能隐藏分类名称。共享账本成员失去访问权限后，不再签发新的图片读取地址。

### 5.6 分类图标与历史账单

- 分类图标变更不修改历史账单记录；
- 历史账单展示当前分类名称和当前分类图标；
- 分类停用后，历史账单仍显示原分类图标；
- 分类图标被替换后，旧图片在没有任何当前引用时进入清理流程；
- 图标资源清理不能删除当前分类正在使用的图片；
- 图标损坏或已被清理时，历史账单使用统一降级图标。

## 6. 统计图表视觉需求

统计页继续按照“收支统计 → 收支趋势 → 分类统计 → 账单汇总”的顺序展示，不增加资产、负债和净资产模块。

### 6.1 趋势图

- 支持支出、收入、结余三个指标 Tab；
- 切换指标只改变图表渲染，不重复请求已有的统计数据；
- 支出使用红色系，收入使用绿色系，结余使用蓝色系；
- 结余为负数时显示负号，并使用负向颜色；
- 显示零基线；
- 根据当前数据显示 2～3 个辅助刻度；
- 图表轴使用紧凑金额，例如 `324.9 万`；
- Tooltip 使用完整金额，例如 `¥3,249,463.00`；
- 柱状图宽度、间距、圆角和容器高度稳定；
- 零值周期保留时间轴，不生成假柱；
- 没有数据时显示空状态，不绘制全零趋势；
- 图表不能因为金额长度、窗口宽度或 Tooltip 打开而导致页面横向溢出。

趋势图需要保留服务端返回的周期、三类金额、账单数量和下钻时间范围，不由前端重新计算金额或日期边界。

### 6.2 趋势图 Tooltip

点击趋势柱后显示数据 Tooltip：

```text
┌──────────────────────────┐
│ 2026年11月12日            │
├──────────────────────────┤
│ 支出       ¥3,249,463.00 │
│ 收入           ¥8,200.00 │
│ 结余      -¥3,241,263.00 │
│ 账单                 28 笔 │
│ [查看本周期账单]          │
└──────────────────────────┘
```

交互规则：

- 点击柱后高亮当前柱，并在图表可视范围内显示 Tooltip；
- Tooltip 显示完整周期、支出、收入、结余和账单数量；
- 当前选中的指标在 Tooltip 中使用强调样式；
- 点击“查看本周期账单”才进入账单页；
- 点击空白区域、按 `Esc` 或再次点击当前柱可以关闭 Tooltip；
- 桌面端支持鼠标悬停和键盘聚焦；
- 移动端使用点击，不依赖 hover；
- Tooltip 自动调整上下左右位置，不能被屏幕边缘裁切；
- 账单数量为 0 时不显示可下钻按钮。

### 6.3 分类环形图

- 中心显示“总支出”或“总收入”及完整金额；
- 中心标题和金额必须位于环形图内圈中心；
- 金额较长时自动缩小字号或换行，不能压到环形边界外；
- 环形图最多显示金额最高的 6～8 个分类；
- 剩余分类合并为“其他”；
- 分类列表仍展示完整分类，不因图表聚合而丢失明细；
- 图表、进度条、分类图标和分类列表使用相同颜色；
- 占比低于 1% 时，列表显示 `<1%`，Tooltip 显示精确占比；
- 没有分类数据时显示空环和“暂无数据”，不显示假金额。

“其他”是统计展示聚合项，不代表新的账单分类。它不能被保存为分类，也不能改变账单的 `categoryId`。

### 6.4 分类图表 Tooltip

点击环形图扇区显示：

```text
┌──────────────────────────┐
│ [餐具] 餐饮              │
├──────────────────────────┤
│ 金额          ¥1,249.50 │
│ 占比             69.98% │
│ 账单                17 笔 │
│ [查看该分类账单]         │
└──────────────────────────┘
```

“其他” Tooltip 显示：

```text
其他分类
金额：¥xxx
占比：xx%
包含：5 个分类，12 笔账单
```

交互规则：

- 点击扇区后高亮当前扇区，并显示分类图标、名称、金额、占比和账单数量；
- 点击“查看该分类账单”进入当前分类的账单下钻；
- 点击“其他”时只展示聚合数据，不跳转到不存在的分类 ID；
- 点击分类列表仍保留现有的一级分类下钻和账单下钻；
- Tooltip 关闭规则与趋势图一致；
- 图表扇区必须支持键盘聚焦和可访问名称；
- 不能只依靠颜色区分分类，必须同时展示名称、图标或文字标签。

## 7. 统计数据语义

### 7.1 趋势数据

每个趋势周期至少需要提供：

```text
fromDate
toDate
expenseCents
incomeCents
netCents
transactionCount
drilldown.from
drilldown.to
```

Tooltip 中的金额使用整数分转换后的精确金额展示。日期范围使用统计服务端返回的账本时区和 UTC 半开区间，前端不按设备时区重新计算。

### 7.2 分类数据

每个分类统计项至少需要提供：

```text
categoryId
categoryRootId
parentId
bucketType
name
iconSource
iconKey
iconAssetId
color
amountCents
percentage
transactionCount
drilldown
```

统计接口返回的分类图标数据必须与分类查询接口保持同一语义。统计页不能出现分类列表有图标、图表 Tooltip 没有图标的情况。

### 7.3 统计下钻

统计图表下钻继续携带：

- 当前账本；
- 服务端返回的 `startAt` 和 `endAt`；
- 收支类型；
- 一级分类或具体分类条件；
- 当前公共筛选条件。

点击 Tooltip 的下钻按钮后，账单页必须显示与 Tooltip 对应的同一时间范围和分类条件，不能只跳到当前月份或当前页面默认范围。

## 8. 页面状态和异常处理

### 8.1 分类图标状态

| 状态 | 页面行为 |
| --- | --- |
| 图标加载中 | 显示固定尺寸骨架，不改变列表布局 |
| 图标加载成功 | 显示图片或图标库图标 |
| 图标加载失败 | 使用分类颜色和首字降级 |
| 图片上传中 | 显示进度，保存按钮进入 loading |
| 图片上传失败 | 显示失败原因和重试入口，保留其他表单内容 |
| 分类保存失败 | 保留用户输入和图标选择，不关闭编辑面板 |
| 分类停用 | 新账单不可选择，历史账单继续显示图标 |
| 无权限 | 不显示编辑入口，接口返回统一权限错误 |
| 当前离线 | 图标库选择可继续预览，图片上传和保存不可执行 |

### 8.2 统计图状态

| 状态 | 页面行为 |
| --- | --- |
| 初次加载 | 模块显示稳定高度骨架 |
| 部分加载 | 不影响其他统计模块显示 |
| 无数据 | 显示空状态，不绘制假趋势或假分类 |
| Tooltip 打开 | 高亮当前数据项，其他内容保持可读 |
| Tooltip 被遮挡 | 自动调整位置，不超出可视区域 |
| 查询失败 | 保留当前时间范围，显示模块级重试 |
| 下钻失败 | 保留统计页状态，提示账单列表暂时不可用 |
| 账本切换 | 关闭 Tooltip 并清理旧账本统计数据 |

## 9. 权限与隐私

- 所有分类图标查询必须经过当前用户的活跃账本成员校验；
- 只有 `OWNER` 可以新增、编辑、停用和替换分类图标；
- `EDITOR` 和 `VIEWER` 可以读取当前账本启用分类图标；
- 共享账本成员只能读取自己有权访问的账本图标资源；
- 私有账户账单仍遵循现有私人账户可见性规则；
- 图片对象存储使用私有 Bucket，不返回永久公开图片地址；
- 图片读取地址使用短期签名地址；
- 分类图标资源不能写入应用日志、错误日志或审计日志的图片内容；
- 管理员后台默认不直接修改用户分类图标，涉及敏感资源时沿用平台管理员权限和审计规则。

## 10. 验收标准

### 10.1 分类图标

- [ ] 新建账本的默认一级和二级分类都有预置图标；
- [ ] 记账面板、账单列表、分类管理和统计列表使用同一分类图标；
- [ ] Owner 可以在图标库中搜索、选择和恢复默认图标；
- [ ] Owner 可以上传 PNG、JPEG 或 WebP 图片作为分类图标；
- [ ] 超过 2MB、类型不允许或文件头不匹配时上传失败；
- [ ] 取消编辑不会留下可读的临时图片资源；
- [ ] 分类图片加载失败时显示稳定的降级图标；
- [ ] Editor 和 Viewer 看不到分类图标编辑入口；
- [ ] 修改分类图标不改变分类 ID、历史账单关联和统计金额；
- [ ] 停用分类后历史账单仍然显示分类图标；
- [ ] 共享账本成员刷新后看到同一个分类图标。

### 10.2 统计图表

- [ ] 趋势图点击柱子后显示精确周期、支出、收入、结余和账单数量；
- [ ] 趋势 Tooltip 可以进入对应周期的账单列表；
- [ ] 环形图点击扇区后显示分类图标、名称、金额、占比和账单数量；
- [ ] 分类 Tooltip 可以进入对应分类的账单列表；
- [ ] 分类数量较多时图表最多展示 6～8 个分类和“其他”；
- [ ] 分类列表仍展示完整分类明细；
- [ ] 环形图中心金额不会与边界或其他内容重叠；
- [ ] 金额跨度较大时趋势图仍显示清晰的零基线和刻度；
- [ ] Tooltip 在移动端、桌面端和键盘操作下均可使用；
- [ ] Tooltip 不会被屏幕边界裁切；
- [ ] 统计图表不依赖颜色作为唯一信息表达；
- [ ] 切换账本、时间范围或统计类型后，旧 Tooltip 和旧数据不会残留。

## 11. 后续文档与实施顺序

第五期需求确认后，按以下顺序补充开发文档：

## 12. 实现边界

本需求确认后，技术实现仍需单独确认以下事项：

- Tabler 精选分类图标的最终映射表；
- 分类图片资源是否计入现有用户对象存储配额；
- 图片上传使用预签名 PUT 还是预签名 POST Policy；
- 图标库和图片资源的缓存时间；
- 统计图“其他”聚合由服务端返回还是由前端基于完整列表计算。

这些事项不改变本需求中的用户行为和验收标准。
