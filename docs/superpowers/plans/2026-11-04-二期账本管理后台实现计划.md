# 二期账本管理后台实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 实现二期普通用户账本偏好、时区、复制和受限删除接口，并保持历史账本及成员访问兼容。

**Architecture:** Prisma 持久化账本时区、用户当前/默认账本偏好和复制幂等记录。账本 Service 继续以活跃成员关系作为访问边界；复制和删除使用数据库事务，复制通过唯一约束防止并发重试，删除通过行锁与事务内资格复核保护账本数据。

**Tech Stack:** NestJS 11、Prisma 7、PostgreSQL、class-validator、Jest。

**Spec:** `docs/api/账本与成员接口.md`、`docs/需求/二期账本管理与统计需求.md`

## Global Constraints

- `Ledger.timezone` 使用 IANA 标识，默认值为 `Asia/Shanghai`。
- `UserLedgerPreference` 只保存偏好，不授予账本访问权；读写都重新验证 `LedgerMember(status=ACTIVE)`。
- 账本复制只复制展示设置和分类树，不复制交易、账户、成员、邀请、余额或审计历史。
- 复制请求使用数据库唯一约束 `[userId, clientRequestId]`，不能依赖进程内锁。
- 删除账本必须保护所有交易（含软删除记录）、其他活跃成员、有效待处理邀请和用户最后一本可访问账本。
- 历史 `isArchived` 数据不得丢失或继续被列表隐藏；二期不新增归档写接口。
- 业务行为变更先写失败测试；Service 只在 Prisma 边界使用浅层 Mock。
- 每个独立模块完成类型检查、相关测试和差异检查后单独提交；提交信息使用中文 Conventional Commit。
