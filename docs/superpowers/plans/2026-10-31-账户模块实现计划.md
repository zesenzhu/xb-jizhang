# 账户模块实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在普通用户账本权限基础上实现账户查询、创建、编辑、停用和重新启用能力。

**Architecture:** 账户资源始终通过当前用户的活跃 `LedgerMember` 关系授权。共享账户由 `OWNER` 管理，私人账户由账户所有者管理；账户余额字段由账单模块维护，账户接口只读余额。

**Tech Stack:** NestJS 11、Prisma 7、PostgreSQL、class-validator、Jest。

**Spec:** `docs/requirements/账户与分类需求.md`、`docs/api/账户与分类接口.md`、`docs/architecture/账单领域技术设计.md`
