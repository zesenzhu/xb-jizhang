# 我的页面 `/user/profile`

底部主导航的第三个入口。二期只做入口整理，个人资料与账号安全沿用一期能力。

## 1. 页面结构与布局

```text
┌────────────────────────────────────────┐
│                    我的                 │
├────────────────────────────────────────┤
│ 👤 昵称                                 │
│    @username                            │
├────────────────────────────────────────┤
│ 个人资料                            ›   │
│ 账号与安全                          ›   │
│ 我的邀请                       2 条 ›   │
│ 本地缓存与离线数据                  ›   │
│ 帮助与关于                          ›   │
└────────────────────────────────────────┘
```

- 不重复列出账本；账本切换与管理入口在账本页（需求 10）。
- 不新增平台管理员入口。

## 2. 数据来源

| 用途 | 接口 | 缓存键 |
| --- | --- | --- |
| 当前用户 | `GET /users/me` | `['user','me']` |
| 持我待处理邀请数 | `GET /invitations` | `['user','invitations']` |

邀请数量只用于「我的邀请」右侧的角标，为空时不渲染。

## 3. 交互规则

| 项 | 行为 |
| --- | --- |
| 个人资料 | 沿用一期页面 |
| 账号与安全 | 修改密码等一期能力 |
| 我的邀请 | 进入 `/user/invitations`，显示待处理邀请并可接受/拒绝 |
| 本地缓存与离线数据 | 进入缓存管理区域，查看本地占用、待同步账单和最近同步时间 |
| 帮助与关于 | 静态页 |
| 退出登录 | 清理全部 `user` / `ledgers` / `ledger` 前缀缓存后跳登录页 |

## 4. 状态矩阵

| 状态 | 触发 | 呈现 |
| --- | --- | --- |
| 未加载 | 用户信息请求中 | 头部骨架 |
| 有邀请 | `items.length > 0` | 角标显示条数 |
| 无邀请 | `items.length === 0` | 不显示角标 |

## 5. 组件清单

复用 `UserNavShell`、`Skeleton`；「我的邀请」页新建 `components/invitation/MyInvitations.tsx`。

## 6. 实现状态

已交付：`ProfilePage` + `ProfileView/ProfileEntryList`。「个人资料」「账号与安全」「帮助与关于」用页面内 `BottomSheet` 就地完成（不新增路由），「我的邀请」进入 `/user/invitations`。退出登录清理 `user`/`ledgers`/`ledger` 前缀缓存、本地账单记忆与邀请会话。

待交付：增加“本地缓存与离线数据”入口。缓存管理需要显示当前账号的图片缓存占用、账单快照数量、待同步账单数量和最近同步时间，并提供清理图片缓存、清理已同步账单快照、清理全部本地数据三个操作。清理已同步数据不能删除待同步账单；清理全部数据必须二次确认并明确未同步内容会丢失。
