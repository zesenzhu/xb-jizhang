# 我的页面 `/user/profile`

底部主导航的第三个入口。二期只做入口整理，个人资料与账号安全沿用一期能力。

## 1. 页面结构与布局

```text
┌────────────────────────────────────────┐
│                    我的                 │
├────────────────────────────────────────┤
│ 👤 昵称                                 │
│    @username                            │
├────────────────────────────────────────┤
│ 个人资料                            ›   │
│ 账号与安全                          ›   │
│ 我的邀请                       2 条 ›   │
│ 帮助与关于                          ›   │
└────────────────────────────────────────┘
```

- 不重复列出账本；账本切换与管理入口在账本页（需求 10）。
- 不新增平台管理员入口。

## 2. 数据来源

| 用途 | 接口 | 缓存键 |
| --- | --- | --- |
| 当前用户 | `GET /users/me` | `['user','me']` |
| 持我待处理邀请数 | `GET /invitations` | `['user','invitations']` |

邀请数量只用于「我的邀请」右侧的角标，为空时不渲染。

## 3. 交互规则

| 项 | 行为 |
| --- | --- |
| 个人资料 | 沿用一期页面 |
| 账号与安全 | 修改密码等一期能力 |
| 我的邀请 | 进入 `/user/invitations`，显示待处理邀请并可接受/拒绝 |
| 帮助与关于 | 静态页 |
| 退出登录 | 清理全部 `user` / `ledgers` / `ledger` 前缀缓存后跳登录页 |

## 4. 状态矩阵

| 状态 | 触发 | 呈现 |
| --- | --- | --- |
| 未加载 | 用户信息请求中 | 头部骨架 |
| 有邀请 | `items.length > 0` | 角标显示条数 |
| 无邀请 | `items.length === 0` | 不显示角标 |
