# 统计页 `/user/statistics`

当前账本在选定时间范围内的收支统计。底部主导航的「统计」入口。**只读页面，不显示记账按钮。**

二期统计页基础能力已交付。第五期趋势 Tooltip、分类环形图交互、图标统一展示和“其他”展示聚合见[统计图表交互](./统计图表交互.md)，跨页面实现约束见[第五期前端实施设计](./第五期前端实施设计.md)。本文继续维护统计页整体布局、数据查询和页面级状态。

范围以需求第 9 节为准。参考截图中的「报销统计」「流转统计」「净资产趋势」「总资产/总负债」均属二期明确排除的功能，不实现。

## 1. 页面结构与布局

顺序固定为：概览 → 趋势 → 分类 → 汇总，与需求 9.1 一致。

## 2. 数据来源

四个接口共用同一份 `range` 上下文，一次切换只发一轮请求。

| 用途 | 接口 | 缓存键 |
| --- | --- | --- |
| 概览 | `GET /statistics/overview` | `['ledger',id,'statistics','overview',ctx]` |
| 趋势 | `GET /statistics/trend` | `[...,'trend',ctx]` |
| 分类 | `GET /statistics/categories` | `[...,'categories',ctx]` |
| 汇总 | `GET /statistics/periods` | `[...,'periods',ctx]` |

`staleTime` 统一 30s（与账单列表一致）。四个 key 的首段都是 `ledger`，退出登录时按前缀清理。

### 2.1 统一查询上下文

```text
ctx = {
  period: 'WEEK' | 'MONTH' | 'YEAR' | 'ALL' | 'RANGE'
  anchorDate?: 'YYYY-MM-DD'      // WEEK/MONTH/YEAR
  fromDate?, toDate?: 'YYYY-MM-DD'  // RANGE
  granularity?: 'AUTO' | 'DAY' | 'MONTH' | 'YEAR'
  accountId?, payerId?, keyword?     // 公共过滤
  // 接口专属
  metric?: 'EXPENSE' | 'INCOME' | 'NET'          // trend
  type?: 'EXPENSE' | 'INCOME'                     // categories
  categoryLevel?: 'ROOT' | 'CHILD'                // categories
  categoryRootId?: string                         // categories
  sortBy?, sortOrder?, includeComparison?         // categories
}
```

**所以接口专用参数只进各自的 queryKey**：把 `metric` 塞进 overview 的 key 会导致切换趋势 Tab 时概览重复请求。

### 2.2 时间范围计算

前端**不自己算范围边界**。日期以账本时区的本地日期传给服务端，响应里带回 `startAt`/`endAt`：

```text
响应 range = { period, timezone, fromDate, toDate, startAt, endAt, granularity }
```

下钻到账单页时直接用 `startAt`/`endAt`，不要用浏览器时区重算 —— 账本时区（`Asia/Shanghai`）与设备时区可能不同。

`anchorDate` 取当前导航位置对应的日期：

| 维度 | 导航 | 传入 |
| --- | --- | --- |
| 周 | 上一/下一周 | 该周任一天 |
| 月 | 上一/下一月 | 该月 1 日 |
| 年 | 上一/下一年 | 该年 1 月 1 日 |
| 全部 | 无导航 | 不传 |
| 范围 | 日期选择器 | `fromDate`/`toDate` |

不允许导航到未来：`anchorDate` 超过账本时区今天时，下一箭头禁用。

## 3. 交互规则

### 3.1 时间维度

| 场景 | 行为 |
| --- | --- |
| 切换 Tab | 保留账本与公共过滤，重置导航到当前周期，四个模块同时刷新 |
| 切换周期 | 同上；旧数据立即置空进入骨架，不保留上一个范围 |
| `ALL` | 隐藏左右箭头，`range` 可能为 `null`（无可见账单） |
| `RANGE` | 展开日期选择器；`toDate` 不能晚于今天 |

需求 9.2 明确「切换时间维度或范围时，所有概览、图表、分类和汇总同时刷新，不保留上一个范围的旧数据」。

### 3.2 趋势图

- 三个 Tab：支出 / 收入 / 结余，对应 `metric`。
- **一次请求已返回 `expenseCents`/`incomeCents`/`netCents`**，切换 Tab 只改渲染，不重新请求。
- `hasData=false` 时显示空状态，不画全零图。
- 零值周期照常绘制（服务端会补全连续周期）。
- 点击柱子显示该周期日期与金额；点击详情跳到账单页并带该周期的 `drilldown.from/to`。

### 3.3 分类统计

| 场景 | 行为 |
| --- | --- |
| 切换支出/收入 | `type` 变化，图、总额、占比、列表全部重算 |
| 点击一级分类 | 进入二级视图：`categoryLevel=CHILD` + `categoryRootId` |
| 二级视图首行 | 「{一级名}（未细分）」，对应 `bucketType=ROOT_DIRECT` |
| 点击分类行 | 跳账单页并带 `categoryRootId`（一级）或 `categoryId`（ROOT_DIRECT / 二级） |
| 排序 | `sortBy` 金额/占比 |
| 空总额 | 占比全显示 0，环形图显示空态 |

需求 9.5 要求支持一级/二级层级切换；`ROOT_DIRECT` 行避免下钻后丢失直接记在一级上的金额。

### 3.4 账单汇总

- 行由服务端返回，含连续零值周期，前端不裁剪。
- 顶部「总计」用 `summary`，不是前端累加。
- 点击行跳账单页，`from`/`to` 用该行 `drilldown`。
- 推广粒度切换（日/月/年）只在当前范围允许的粒度内提供。

### 3.5 下钻

统一规则：跳转 `/user` 并带上

```text
ledgerId（当前账本）
+ startAt/endAt（来自 drilldown 的 UTC 半开区间）
+ 公共过滤（accountId/payerId/keyword）
+ 分类条件（categoryRootId 或 categoryId）
+ type（分类统计下钻时）
```

账本页已支持 `categoryRootId` 参数。分类统计下钻时优先使用服务端返回的 `categoryRootId`、`categoryId` 或 `uncategorized`，不在前端重新推导分类层级。

## 4. 状态矩阵

| 状态 | 触发 | 呈现 |
| --- | --- | --- |
| 首次加载 | 四个请求进行中 | 各模块独立骨架 |
| 部分加载 | 某模块先返回 | 该模块先渲染，其余继续骨架 |
| 无数据 | `hasData=false` / `totalCents=0` | 零值 + 空图表，不残留旧数据 |
| 加载失败 | 请求错误 | 模块级错误 + 重试，保留时间范围 |
| `ALL` 无账单 | `range=null` | 「还没有可统计的账单」 |
| 未来导航 | 当前周期已是最后一期 | 下一箭头禁用 |
| 权限不足 | `40421` | 提示并回到账本页 |

需求 12 要求「统计加载失败：保留已选时间范围，提供重试；不得继续展示其他时间范围或账本的旧数据」。

### 图表实现

**自绘 SVG，不引第三方图表库。** 理由：

- 只有柱状图 + 环形图两种，用 `path` 与 `rect` 就能画，不需要坐标系缩放/拖拽
- 避免 ~100KB 依赖和深色主题适配
- 主题色直接取 `--color-financial-expense` / `--color-financial-income`，与全站一致

`CategoryDonut` 用 `stroke-dasharray` 画扇区，`TrendChart` 用等比高度的 `rect`。
