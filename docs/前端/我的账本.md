# 我的账本 `/user/ledgers`

账本的查询、创建、切换与分组管理。这是二期新增的二级页面，从账本页顶部的切换按钮进入。

## 1. 页面结构与布局

```text
┌────────────────────────────────────────┐
│ ‹              我的账本            ＋   │  ← SecondaryLayout，隐藏底栏
├────────────────────────────────────────┤
│ 个人账本                                │
│ ┌────────────────────────────────────┐ │
│ │ 💡 我的账本            ✓当前   ⋯   │ │
│ └────────────────────────────────────┘ │
│ ┌────────────────────────────────────┐ │
│ │ ✈️ 旅行账本                    ⋯   │ │
│ └────────────────────────────────────┘ │
│                                        │
│ 共享账本                                │
│ ┌────────────────────────────────────┐ │
│ │ 🏠 家庭账本  OWNER · 4 人      ⋯   │ │
│ └────────────────────────────────────┘ │
│ ┌────────────────────────────────────┐ │
│ │ 🎉 聚会账本  VIEWER · 3 人     ⋯   │ │
│ └────────────────────────────────────┘ │
└────────────────────────────────────────┘
```

- 按 `type` 分组：个人账本在前，共享账本在后；组内按 `createdAt` 升序，保证顺序稳定。
- 卡片主体点击 = 切换账本并返回账本页；`⋯` 是独立点击区，不触发切换。
- `＋` 在顶栏右侧，进入创建流程。
- 当前账本卡片显示 `✓当前` 与主题色描边。
- 共享账本卡片显示角色徽标与成员数（`memberCount`）。

## 2. 数据来源

| 用途 | 接口 | 缓存键 | staleTime |
| --- | --- | --- | --- |
| 账本列表 | `GET /ledgers` | `['ledgers','list',{}]` | 60s |
| 当前/默认账本 | `GET /me/ledger-preferences` | `['ledgers','preferences']` | 60s |
| 切换当前账本 | `PATCH /me/ledger-preferences` | 成功后失效上述两个键 | — |

`GET /ledgers` 返回的摘要已包含 `memberRole`、`memberCount`、`isCurrent`、`isDefault`、`timezone`，列表页不需要为每张卡片单独请求。

**切换必须走偏好接口**，不能只改本地 store：

```text
切换账本 → PATCH /me/ledger-preferences { currentLedgerId }
        → 失效 ledgers + preferences
        → 失效该用户全部 ledger 前缀的账单/统计缓存
        → 写 workspaceStore.currentLedgerId
        → router 返回账本页
```

需求 5.2 要求“旧账本的统计、流水和成员信息不得短暂残留”，所以切换后必须清掉旧账本的查询缓存，而不是只换 `currentLedgerId`。

### 2.1 权限差异

| 角色 | 卡片操作菜单 |
| --- | --- |
| `OWNER` | 账本设置、复制账本、删除（满足条件时） |
| `EDITOR` / `VIEWER` | 仅「查看账本信息」；不渲染创建、编辑、删除、邀请 |

需求 7.1 要求“Owner 可见账本操作菜单”，Viewer 可切换但看不到管理操作。

## 3. 交互规则

| 场景 | 行为 |
| --- | --- |
| 点击卡片主体 | 切换为该账本，返回账本页 |
| 点击当前账本卡片 | 仅返回，不重复请求 |
| 点击 `⋯` | 打开操作面板：账本设置 / 复制 / 删除 |
| 点击 `＋` | 进入创建账本 |
| 列表为空 | 显示空态 + 「新建账本」按钮；不允许出现无账本状态 |
| 切换失败 | 保留原当前账本，Toast 提示并刷新列表 |
| 无网络 | 使用缓存渲染，切换按钮禁用并提示 |

## 4. 状态矩阵

| 状态 | 触发 | 呈现 |
| --- | --- | --- |
| 首次加载 | 无缓存且请求中 | 分组骨架卡 ×4 |
| 有数据 | 正常 | 分组卡片列表 |
| 加载失败 | 请求错误且无缓存 | 错误文案 + 重试 |
| 空列表 | `items.length === 0` | 「还没有账本」+ 新建按钮 |
| 切换中 | 偏好请求进行中 | 目标卡片显示 loading，其他卡片禁点 |
