# 统计图表交互

本文定义第五期统计页趋势图和分类环形图的展示、Tooltip、可访问性和下钻交互。跨页面的总方案、缓存、状态和测试边界见[第五期前端实施设计](./第五期前端实施设计.md)。统计金额和日期边界以服务端响应为准，前端只负责展示和传递下钻参数。

## 1. 共同原则

- 统计页继续按“收支统计 → 收支趋势 → 分类统计 → 账单汇总”展示；
- 不增加资产、负债、净资产、转账或预算统计；
- 时间范围、周期边界、金额、账单数和下钻区间来自服务端；
- 切换账本、时间范围或分类类型时清空旧 Tooltip 和旧选择状态；
- 图表不能只依靠颜色表达信息，必须同时使用文字、图标、数值或键盘焦点；
- 图表容器使用稳定高度和 `min-width: 0`，Tooltip 不得造成页面横向溢出。

## 2. 趋势图

### 2.1 数据

趋势接口每个周期至少使用：

```text
fromDate
toDate
expenseCents
incomeCents
netCents
transactionCount
drilldown.from
drilldown.to
```

指标 Tab 为支出、收入、结余。一次响应已包含三种金额，切换指标只改变柱子读取的字段和颜色，不重复请求。

### 2.2 视觉规则

- 支出使用红色语义色；
- 收入使用绿色语义色；
- 结余使用蓝色语义色，负数使用负向颜色；
- 显示零基线；
- 根据当前数据生成 2～3 个辅助刻度；
- 坐标轴金额使用紧凑格式，如 `324.9 万`；
- Tooltip 使用完整金额，如 `¥3,249,463.00`；
- 零值周期保留时间轴但不绘制假柱；
- `hasData=false` 时显示空状态，不绘制全零趋势；
- 柱宽、间距、圆角和图表容器高度稳定。

### 2.3 Tooltip

点击或键盘聚焦某个周期后，在图表可视范围内显示：

```text
周期
支出       ¥3,249,463.00
收入           ¥8,200.00
结余      -¥3,241,263.00
账单                 28 笔
[查看本周期账单]
```

行为：

- 当前柱高亮，Tooltip 中当前指标强调；
- 桌面端支持悬停和键盘聚焦；
- 移动端使用点击，不依赖 hover；
- 点击空白、再次点击当前柱或按 `Esc` 关闭；
- 账单数为 0 时不显示下钻按钮；
- 下钻直接使用该周期 `drilldown.from` 和 `drilldown.to`；
- 不按浏览器时区重新计算周期日期。

## 3. 分类环形图

### 3.1 图表数据

服务端返回完整分类明细。前端按 `amountCents` 降序取金额最高的 6～8 项，其余合并为展示项“其他”。“其他”只存在于图表视图：

- 不创建新的分类 ID；
- 不改变分类列表；
- 不出现在分类管理；
- 不提供分类 ID 下钻；
- 金额、账单数和占比是其余分类的合计。

分类列表继续展示服务端返回的完整分类明细。图表、进度条、分类列表和 Tooltip 使用同一个 `color` 与图标描述。

### 3.2 中心区域

环形中心显示“总支出”或“总收入”以及完整金额：

- 标题和金额在内圈中心对齐；
- 长金额自动缩小或换行；
- 容器有固定宽高；
- 没有分类数据时显示空环和“暂无数据”；
- 不显示假金额或全零伪数据。

### 3.3 Tooltip

普通分类显示：

```text
[图标] 餐饮
金额          ¥1,249.50
占比             69.98%
账单                17 笔
[查看该分类账单]
```

“其他”显示：

```text
其他分类
金额：¥xxx
占比：xx%
包含：5 个分类，12 笔账单
```

行为：

- 点击扇区或键盘聚焦后高亮当前扇区；
- 点击“查看该分类账单”进入对应分类下钻；
- 普通一级分类使用 `categoryRootId`；
- 二级分类和 `ROOT_DIRECT` 使用 `categoryId`；
- 未分类使用 `uncategorized=true`；
- “其他”只有展示，不显示下钻按钮；
- 点击空白、再次点击当前扇区或按 `Esc` 关闭。

## 4. 分类图标与金额格式

- 分类项使用[分类图标选择](./分类图标选择.md)定义的统一渲染器；
- 图标加载失败时使用颜色和首字降级，不影响金额和名称；
- 列表占比小于 1% 时显示 `<1%`；
- Tooltip 显示服务端返回的精确占比；
- 金额使用整数分转换工具，禁止用浮点数重新计算业务金额；
- `comparison` 的环比金额沿用服务端结果，不在 Tooltip 中自行推导。

## 5. 下钻参数

下钻到账单页必须携带：

```text
ledgerId
startAt
endAt
type
categoryRootId 或 categoryId 或 uncategorized
accountId
payerId
keyword
```

`startAt` 和 `endAt` 来自服务端 `drilldown` 的 UTC 半开区间。路由跳转失败时保留统计页状态，显示账单列表暂不可用，不清空当前统计结果。

## 6. 可访问性与响应式

- 图表使用 `role="img"` 或可聚焦的数据项按钮，并提供周期/分类的可访问名称；
- 每个可交互柱和扇区支持键盘聚焦；
- `Enter` 或 `Space` 打开 Tooltip，`Esc` 关闭；
- Tooltip 使用固定最大宽度，超长金额允许换行；
- Tooltip 靠近边界时自动翻转或调整位置；
- 移动端 Tooltip 不依赖 hover，桌面端悬停不能替代键盘和点击；
- 图表内容、图例和 Tooltip 在窄屏下不产生横向滚动；
- 骨架、空状态和错误状态使用与正式内容相同的模块高度。

## 7. 状态矩阵

| 状态 | 页面行为 |
| --- | --- |
| 初次加载 | 显示稳定高度骨架 |
| 部分加载 | 只影响对应统计模块 |
| 无数据 | 显示空状态，不绘制假图表 |
| Tooltip 打开 | 当前项高亮，其他内容保持可读 |
| Tooltip 被遮挡 | 自动调整位置 |
| 查询失败 | 保留时间范围，显示模块级重试 |
| 下钻失败 | 保留统计页状态并提示 |
| 切换账本 | 清空旧数据、旧 Tooltip 和旧选择 |

## 8. 验收清单

- [ ] 趋势图点击柱子显示完整周期、三类金额和账单数；
- [ ] 趋势 Tooltip 能进入对应周期账单；
- [ ] 环形图点击扇区显示图标、名称、金额、占比和账单数；
- [ ] 环形图最多显示 6～8 个分类和“其他”；
- [ ] “其他”不产生虚假分类下钻；
- [ ] 分类列表仍展示完整明细；
- [ ] 长金额不会破坏环形图中心布局；
- [ ] Tooltip 支持移动端点击、桌面端悬停和键盘操作；
- [ ] Tooltip 不被屏幕边界裁切；
- [ ] 图表不依赖颜色作为唯一信息；
- [ ] 切换账本、时间范围或分类类型后旧 Tooltip 和旧数据不会残留。
