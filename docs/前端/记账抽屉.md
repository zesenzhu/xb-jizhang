# 记账抽屉

从账单页右下角 FAB 打开的底部面板，是一期唯一的记账入口。

## 1. 页面结构与布局

```text
┌───────────────────────────────────────┐
│ ✕                    支出 收入       账本名 │  ← 顶栏
├───────────────────────────────────────┤
│  [🍜] [🛒] [👕] [🧴] [📱]             │  ← 分类九宫格
│  [💄] [🧖] [📲] [🏠] [🚌]             │     可纵向滚动
│  ...                                  │
├───────────────────────────────────────┤
│ 选择账户  报销  优惠  图片  标签   ⚙    │  ← 快捷字段条（本期仅账户可用）
├───────────────────────────────────────┤
│ ¥ 0.00                                │  ← 金额
│ 🕐 19:02  点击填写备注              ⌃  │  ← 时间 + 备注
├───────────────────────────────────────┤
│  1   2   3   退格                     │
│  4   5   6   清空                     │
│  7   8   9   保存再记                  │
│  .   0   ⌫   完成                     │
└───────────────────────────────────────┘
```

与参考截图的差异：右侧「＋× / －÷」改为「退格 / 清空」，因需求 7.7 只要求数字、小数点、退格、清空。`保存再记` 即需求的「保存并继续」。

高度约视口 88%，顶部保留账单页上下文；宽度 `max-w-md` 居中；`layer='base'`（`z-50`）。

移动端与桌面端共用同一结构，桌面端限制内容宽度，不改为居中弹窗。

## 2. 数据来源

| 用途 | 接口 | 缓存键 | staleTime |
| --- | --- | --- | --- |
| 分类选择 | `GET /ledgers/:id/categories?type=EXPENSE\|INCOME` | `['ledger',id,'categories']` | 5min |
| 账户选择 | `GET /ledgers/:id/accounts` | `['ledger',id,'accounts']` | 5min |
| 付款人选择 | `GET /ledgers/:id/members` | `['ledger',id,'members']` | 5min |
| 商家历史建议 | 无接口，从前端已加载账单提取 | — | — |
| 创建账单 | `POST /ledgers/:id/transactions` | — | — |

创建成功后失效当前 `ledgerId` 下全部 `transactions` 前缀的查询。

### 2.1 创建载荷

```text
{
  clientRequestId,        // crypto.randomUUID()，抽屉打开时生成一次
  type: 'EXPENSE' | 'INCOME',
  amountCents,            // 正整数
  occurredAt,             // ISO 8601，使用账本时区解释后转 UTC
  categoryId,             // 必填，且 type 必须匹配
  accountId?,             // 可选，不传则不影响任何账户余额
  payerId?,               // 可选，仅支出
  title?,                 // 商家/对象，≤200
  note?,                  // ≤200（后端允许 2000，前端按需求收紧）
}
```

`clientRequestId` 在重试时必须复用，保证网络超时重试不产生重复账单。

### 2.2 商家历史建议

一期降级：从当前已加载的账单列表中提取 `title`，去重后按出现顺序取最近 5 条。首次记账时无建议，直接输入。

## 3. 交互规则

### 3.1 打开与关闭

| 场景 | 行为 |
| --- | --- |
| 打开 | 从底部滑入，`transition-transform 240ms ease-out` |
| 关闭（无内容） | ✕ 或遮罩直接关闭 |
| 关闭（有内容） | 弹确认「放弃本次记账吗」，两个操作：继续填写 / 放弃 |
| Esc | 同 ✕，经过未保存确认 |
| 下滑手势 | 不实现（与内部滚动冲突，且需求 7.1 不把手势作为唯一关闭方式） |

`isDirty` 判定：金额非 `0`、已选分类、或商家/备注非空任一成立即为脏。

### 3.2 类型切换

支出 ⇄ 收入时**清空已选分类**，保留金额、时间、账户、商家文本、备注。

理由：支出分类与收入分类不可交叉使用，需求 7.3 明示。

### 3.3 字段交互

| 字段 | 交互 |
| --- | --- |
| 分类格 | 点击进入分类选择浮层（见 `分类选择.md`） |
| 时间 | 点击打开日期时间选择，一期用原生 `datetime-local` |
| 账户 | 点击打开账户列表底部面板，可清除已选 |
| 商家/对象 | 点击进入文本输入，展示最近 5 条历史建议 |
| 备注 | 点击展开文本域，超过 200 字即时截断并提示 |
| 快捷条其余按钮 | 报销/优惠/图片/标签/设置渲染为禁用态，点击提示「即将上线」 |

### 3.4 提交

| 动作 | 行为 |
| --- | --- |
| 完成 | 校验通过 → 创建 → 失效缓存 → 关闭抽屉 → 列表回到顶部 |
| 保存再记 | 校验通过 → 创建 → 失效缓存 → **清空金额/商家/备注，保留类型/时间/分类/账户** → 生成新的 `clientRequestId` → 保持打开 |
| 提交中 | 两个提交键同时禁用，完成键显示 loading |
| 提交失败 | 保留全部输入，抽屉顶部显示错误条，可重试 |

### 3.5 校验时机

| 字段 | 规则 | 时机 |
| --- | --- | --- |
| 金额 | > 0，最多两位小数 | 输入时由键盘约束；为 0 时完成键禁用并显示「请输入金额」 |
| 分类 | 必填，且与类型匹配 | 点提交时校验，未选则滚动到分类区并高亮 + 提示 |
| 时间 | 不允许未来 | 选择后即时提示，不等到提交 |
| 备注 | ≤200 字 | 输入时截断 |
| 权限 | 抽屉打开后成员被降为 `VIEWER` | 提交返回 `40321` 时提示「联系账本所有者调整权限」，不关闭抽屉 |

金额转换用 `lib/bill/amount.ts` 的字符串处理，禁止 `parseFloat` 参与业务判断。

## 4. 状态矩阵

| 状态 | 触发 | 呈现 |
| --- | --- | --- |
| 初始 | 打开 | 类型=支出，金额 `0`，时间=当前，分类未选 |
| 分类加载中 | 分类请求中 | 九宫格 10 个骨架格 |
| 分类加载失败 | 分类请求错误 | 九宫格区显示「分类加载失败」+ 重试 |
| 提交中 | `submitting=true` | 提交键禁用 + loading |
| 提交失败 | 请求错误 | 顶部错误条 + 输入保留 |
| 无权限提交 | `40321` | 提示权限已变化，禁用提交 |
| 离线 | `!isOnline` | 提交键禁用 + 提示「当前离线，无法记账」 |

## 6. 表单状态

组件内 `useReducer`，不入全局 store（抽屉生命周期短，写 store 会在关闭后残留）。

```text
BillFormState {
  mode: 'create'
  type: 'EXPENSE' | 'INCOME'
  amountText: string        // '0' / '12.5' / '12.50'
  categoryId: string | null
  occurredAt: string        // ISO
  accountId: string | null
  title: string
  note: string
  payerId: string | null
  clientRequestId: string
  isDirty: boolean
  submitting: boolean
  error: string | null
}
```

## 7. 验收清单

- [ ] 点击 FAB 弹出抽屉，默认选中支出，键盘可输入金额
- [ ] 金额最多两位小数，第三位小数不接受；小数点只出现一次；退格与清空正常
- [ ] 切换收入后分类被清空，金额、时间、商家文本、备注保留
- [ ] 未选分类点完成：滚动到分类区并高亮提示，不提交
- [ ] 金额为 0 时完成键禁用并显示「请输入金额」
- [ ] 选择未来时间拒绝保存并高亮时间字段
- [ ] 保存成功后抽屉关闭，列表与概览立即出现新账单
- [ ] 保存再记：抽屉保持打开，金额/商家/备注清空，类型/时间/分类/账户保留
- [ ] 有内容时点关闭弹「放弃本次记账吗」，选继续则内容不丢
- [ ] 断网提交失败：输入保留、显示错误、不出现成功状态
- [ ] 重复点击提交只产生一条账单（同一 `clientRequestId`）
- [ ] 提交中两个提交键同时禁用
- [ ] 键盘在抽屉内不出现双倍安全区空白

## 8. 已知降级

| 项 | 降级 | 解除条件 |
| --- | --- | --- |
| 分类两级 | 一期只能选一级分类 | B1 + B2 修复 |
| 默认分类 | 仅 4 条（餐饮/交通/工资/其他收入） | B2 修复后为 16 个一级 |
| 商家建议 | 仅当前已加载分页中出现的 `title` | 后端提供 suggest 接口 |
| 未来时间校验 | 仅前端拦截 | 后端补校验 |
| 备注长度 | 前端限制 200 | D2 收敛后端上限 |
| 账户选择 | 可跳过 | 无需解除（需求即如此） |
