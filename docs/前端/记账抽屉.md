# 记账抽屉

从账单页右下角 FAB 打开的全屏面板（`variant="full"`），是一期唯一的记账入口。

## 1. 页面结构与布局

```text
┌───────────────────────────────────────┐   ← 固定顶部（48px，无下边框）
│ ✕        [支出 收入]        我的账本    │   分段器相对整行居中
├───────────────────────────────────────┤   ← 唯一滚动区，分类紧贴顶栏
│ 选择支出分类              已选：购物    │
│  [🍜] [🛒] [👕] [🧴] [📱]             │     5 列九宫格
│  [💄] [🧖] [📲] [🏠] [🚌]             │     有子级显示角标，点开就地展开
│  ...                                  │
│ ┌ 交通 ────────────────────────┐       │   ← 展开的子分类列表
│ │ 交通            记到一级      │       │
│ │ 打车                          │       │
│ └───────────────────────────────┘       │
├───────────────────────────────────────┤   ← 固定底部（随内容自适应）
│ [💰选择账户] [报销] [优惠] [图片] [标签] │   ← 快捷条
│ ┌───────────────────────────────────┐   │
│ │                             ¥45.60│   │   ← 金额（无标签列，右对齐大字）
│ │ 🕐11:52  商家/对象        备注 ⌄ │   │   ← 时间胶囊 + 标题 + 备注，单行
│ └───────────────────────────────────┘   │
│  1   2   3   退格                     │
│  4   5   6   清空                     │
│  7   8   9   保存再记                  │
│  .   0   ⌫   完成                     │
└───────────────────────────────────────┘
```

三段式固定结构，只有中间一段滚动：

| 段 | 内容 | 行为 |
| --- | --- | --- |
| 顶部 | 关闭、支出/收入、账本名、错误条 | `shrink-0`，不随内容滚动 |
| 中部 | 分类九宫格、已选分类提示 | `flex-1 min-h-0 overflow-y-auto`；分类紧贴顶栏，滚动时键盘位置不动 |
| 底部 | 快捷条 + 金额卡（金额 / 时间 + 标题 + 备注）+ 数字键盘 | `shrink-0`，`bottom` 恒等于视口底部，含 `env(safe-area-inset-bottom)` |

顶栏用 `grid-cols-[1fr_auto_1fr]`：左右两列等宽，中间的分段器 `justify-self-center`，
实测分段器中心与面板中心偏差 `0px`。顶栏不画下边框，靠间距区分层次。

390×844 实测：顶部 48px、滚动区 386px、底部 409px，键盘 `bottom = 844 = innerHeight`。

### 1.1 键盘与提交键

- 12 键布局，`compact` 模式键高 44px。第 4 列为 `row-span-2` 的两行：上「保存再记」、下「完成」。
- 提交键内容横向排列（✓ + 文字），不再竖向堆叠成色块。
- 连续快速点击走 `applyAmountKey` 纯函数累积，同一渲染批次内连点 `888` 得到 `88.8`，不会只剩一个字符。

### 1.2 金额卡

金额、时间、标题、备注合并为一张卡，与参考图一致：

```text
¥45.60                                    ← 26px 等宽粗体，右对齐
🕐11:52   商家/对象（选填）          ⌄    ← 时间胶囊 + 标题 + 备注展开
```

- 时间只显示 `HH:mm`（`formatBillTime`），不显示年月日；三期改为点击胶囊打开独立的日期时间弹窗（见 1.3），不再使用原生 `showPicker()`。
- 备注固定为**一个单行输入框**，始终就地编辑；聚焦时在其上方浮出历史候选（见 1.3）。
- 快捷条里的「报销/优惠/图片/标签」暂不可用，渲染为禁用态；图片附件已移出三期范围，入口保持禁用。

### 1.3 三期改造：键盘覆盖与备注候选

三期把键盘模型定为**覆盖**，并且**备注就在原位输入**：

| 项 | 规则 |
| --- | --- |
| 面板高度 | 保持 `100dvh` 基准，系统键盘弹出不改变面板高度、不整体上推 |
| 底部区 | 键盘弹出时整块抬到键盘上缘（`marginBottom = keyboardInset`），金额卡与备注输入随之上移 |
| 数字键盘 | 被系统键盘覆盖后不再占位；改为一条紧凑的「完成」保存条，保证提交始终可达 |
| 备注输入 | 就在金额卡里那行输入，点击直接唤起系统键盘，不额外弹编辑框、不需要二次确认 |
| 备注候选 | 备注聚焦时在输入上方浮出历史候选，横向可滑动，点选只回填文本 |
| 时间 | 点击时间胶囊先收起键盘，再打开独立居中弹窗，取消不改变原值 |
| 聚焦放大 | 不改字号；由 `viewport` 的 `maximumScale: 1` 抑制 iOS 聚焦自动缩放 |

全屏面板 `h-[100dvh]`，宽度仍 `max-w-md` 居中；顶部安全区由面板 `pt-[env(safe-area-inset-top)]` 处理。分类曾经是独立的二级浮层（`CategoryPickerSheet`），已删除：分类是记账时唯一必填项，放在主面板正中比再开一层更快。

与参考截图的差异：右侧「＋× / －÷」改为「退格 / 清空」，因需求 7.7 只要求数字、小数点、退格、清空。`保存再记` 即需求的「保存并继续」。

高度约视口 88%，顶部保留账单页上下文；宽度 `max-w-md` 居中；`layer='base'`（`z-50`）。

移动端与桌面端共用同一结构，桌面端限制内容宽度，不改为居中弹窗。

## 2. 数据来源

| 用途 | 接口 | 缓存键 | staleTime |
| --- | --- | --- | --- |
| 分类选择 | `GET /ledgers/:id/categories?type=EXPENSE\|INCOME` | `['ledger',id,'categories']` | 5min |
| 账户选择 | `GET /ledgers/:id/accounts` | `['ledger',id,'accounts']` | 5min |
| 付款人选择 | `GET /ledgers/:id/members` | `['ledger',id,'members']` | 5min |
| 商家历史建议 | 无接口，从前端已加载账单提取 | — | — |
| 备注候选 | `GET /ledgers/:id/note-suggestions?limit=10` | `['ledger',id,'notes','suggestions']` | 30s |
| 创建账单 | `POST /ledgers/:id/transactions` | — | — |

创建成功后失效当前 `ledgerId` 下全部 `transactions` 前缀的查询。

### 2.1 创建载荷

```text
{
  clientRequestId,        // crypto.randomUUID()，抽屉打开时生成一次
  type: 'EXPENSE' | 'INCOME',
  amountCents,            // 正整数
  occurredAt,             // ISO 8601，使用账本时区解释后转 UTC
  categoryId,             // 必填，且 type 必须匹配
  accountId?,             // 可选，不传则不影响任何账户余额
  payerId?,               // 可选，仅支出
  title?,                 // 商家/对象，≤200
  note?,                  // ≤200（后端允许 2000，前端按需求收紧）
}
```

`clientRequestId` 在重试时必须复用，保证网络超时重试不产生重复账单。

### 2.2 商家历史建议

一期降级：从当前已加载的账单列表中提取 `title`，去重后按出现顺序取最近 5 条。首次记账时无建议，直接输入。

## 3. 交互规则

### 3.1 打开与关闭

| 场景 | 行为 |
| --- | --- |
| 打开 | 从底部滑入，`transition-transform 240ms ease-out` |
| 关闭（无内容） | ✕ 或遮罩直接关闭 |
| 关闭（有内容） | 弹确认「放弃本次记账吗」，两个操作：继续填写 / 放弃 |
| Esc | 同 ✕，经过未保存确认 |
| 下滑手势 | 不实现（与内部滚动冲突，且需求 7.1 不把手势作为唯一关闭方式） |

`isDirty` 判定：金额非 `0`、已选分类、或商家/备注非空任一成立即为脏。

### 3.2 类型切换

支出 ⇄ 收入时**清空已选分类**，保留金额、时间、账户、商家文本、备注。

理由：支出分类与收入分类不可交叉使用，需求 7.3 明示。

### 3.3 字段交互

| 字段 | 交互 |
| --- | --- |
| 分类格 | 无子级：直接选中；有子级：就地展开子分类列表（不弹第二层浮层） |
| 时间 | 单个 `HH:mm` 胶囊，点击先收起键盘再打开独立日期时间弹窗，不占独立行 |
| 账户 | 点击打开账户列表底部面板，可清除已选 |
| 商家/对象 | 就地输入，展示最近 5 条历史建议 |
| 备注 | 单行输入，聚焦后浮出历史候选；超过 200 字即时截断 |
| 快捷条其余按钮 | 报销/优惠/图片/标签/设置渲染为禁用态，点击提示「即将上线」 |

### 3.4 提交

| 动作 | 行为 |
| --- | --- |
| 完成 | 校验通过 → 创建 → 失效缓存 → 关闭抽屉 → 列表回到顶部 |
| 保存再记 | 校验通过 → 创建 → 失效缓存 → **清空金额/商家/备注，保留类型/时间/分类/账户** → 生成新的 `clientRequestId` → 保持打开 |
| 提交中 | 两个提交键同时禁用，完成键显示 loading |
| 提交失败 | 保留全部输入，抽屉顶部显示错误条，可重试 |

### 3.5 校验时机

| 字段 | 规则 | 时机 |
| --- | --- | --- |
| 金额 | > 0，最多两位小数 | 输入时由键盘约束；为 0 时完成键禁用并显示「请输入金额」 |
| 分类 | 必填，且与类型匹配 | 点提交时校验，未选则滚动到分类区并高亮 + 提示 |
| 时间 | 不允许未来 | 选择后即时提示，不等到提交 |
| 备注 | ≤200 字 | 输入时截断 |
| 权限 | 抽屉打开后成员被降为 `VIEWER` | 提交返回 `40321` 时提示「联系账本所有者调整权限」，不关闭抽屉 |

金额转换用 `lib/bill/amount.ts` 的字符串处理，禁止 `parseFloat` 参与业务判断。

## 4. 状态矩阵

| 状态 | 触发 | 呈现 |
| --- | --- | --- |
| 初始 | 打开 | 类型=支出，金额 `0`，时间=当前，分类未选 |
| 分类加载中 | 分类请求中 | 九宫格 10 个骨架格 |
| 分类加载失败 | 分类请求错误 | 九宫格区显示「分类加载失败」+ 重试 |
| 提交中 | `submitting=true` | 提交键禁用 + loading |
| 提交失败 | 请求错误 | 顶部错误条 + 输入保留 |
| 无权限提交 | `40321` | 提示权限已变化，禁用提交 |
| 离线 | `!isOnline` | 提交键禁用 + 提示「当前离线，无法记账」 |
| 编辑备注 | 聚焦备注 | 底部区抬到键盘上缘，数字键盘让位为紧凑保存条，候选浮在输入上方 |
| 备注候选加载失败 | `note-suggestions` 报错 | 只隐藏候选栏，输入与保存不受影响 |
| 日期弹窗 | 点击时间胶囊 | 先收起键盘，弹窗覆盖在面板之上 |
