# 外观与皮肤 `/user/appearance`

让用户自己决定主题色，以及账本页「总支出」卡片的背景：跟随主题、纯色，或本机图片。图片只存浏览器本地，不上传服务器。

## 1. 页面结构与布局

```text
┌────────────────────────────────────────┐
│ ‹            外观与皮肤                │
├────────────────────────────────────────┤
│ ┌ 预览卡 ────────────────────────────┐  │
│ │ 总支出                              │  │
│ │ ¥1,280.00                           │  │
│ │ 预览效果，实际以账本页为准           │  │
│ └────────────────────────────────────┘  │
├────────────────────────────────────────┤
│ 主题色                                  │
│ [科技蓝] [薄荷绿] [暖琥珀] [深色]        │
├────────────────────────────────────────┤
│ 总支出卡片背景                           │
│ [跟随主题] [纯色] [本地图片]             │
│ （纯色：预设色块 + 自定义取色器）        │
│ （图片：选择/更换图片、移除）            │
├────────────────────────────────────────┤
│ 恢复默认外观                      恢复   │
└────────────────────────────────────────┘
```

- 预览卡与账本页共用同一套背景解析，避免“设置里好看、首页发灰”。
- 主题色只切换 `<html data-theme>`，颜色仍由 `globals.css` 变量定义，不在 JS 里复制一份色值。

## 2. 数据来源

| 用途 | 来源 | 存储位置 |
| --- | --- | --- |
| 主题色选择 | `useSkinStore`（Zustand persist） | `localStorage`：`jizhang.skin.v1` |
| 卡片背景类型与颜色 | 同上 | 同上，仅存选择，不存图片 |
| 卡片背景图片 | `putSkinImage` / `getSkinImage` | IndexedDB：`jizhang-skin` / `images` |
| 预览与首页渲染 | `useSummarySurface` | 运行时由 Blob 生成对象地址 |

**没有接口**。皮肤是纯本地偏好，不进入任何请求，也不同步到其他设备。

### 2.1 为什么不把图片转 base64 存 localStorage

localStorage 只有约 5MB，且只能存字符串；base64 会让体积再涨约 33%。一张 6MB 的原图足以写爆并抛异常。IndexedDB 原生支持 Blob，读写都不需要编码。

## 3. 交互规则

| 操作 | 行为 |
| --- | --- |
| 选主题色 | 立即生效并持久化，无需保存按钮 |
| 选择「跟随主题」 | 卡片用主色做低饱和渐变，不再是纯黑 |
| 选择「纯色」 | 显示预设色块与自定义取色器，选色即时生效 |
| 选择「本地图片」 | 打开系统文件选择；校验通过后写入 IndexedDB 并删除旧图 |
| 更换图片 | 写入新键成功后删除旧键，避免本地残留 |
| 移除图片 | 删除本地图片并回退到「跟随主题」 |
| 恢复默认 | 主题回到科技蓝，背景回到跟随主题，同时清理本地图片 |
| 图片读取失败 | 回退主题背景，不阻断页面渲染，也不报错打扰用户 |

校验规则：仅 `image/jpeg`、`image/png`、`image/webp`；单张 ≤ 6MB；空文件直接拒绝。

可读性：图片模式一律叠一层由浅到深的暗色渐变，否则浅色照片上的白色金额看不清；纯色模式对非法色值回退到安全底色 `#16181d`。

## 4. 状态矩阵

| 状态 | 触发 | 呈现 |
| --- | --- | --- |
| 默认 | 未设置过 | 科技蓝主题 + 跟随主题背景 |
| 纯色 | 选中「纯色」 | 预设色块 + 自定义取色器 |
| 有本地图片 | 已选图 | 显示「更换图片」「移除」 |
| 图片保存中 | 写 IndexedDB | 按钮禁用，防重复点 |
| 图片过大/格式不符 | 校验失败 | 就地错误提示，保留原设置 |
| 本地存储不可用 | 隐私模式/老浏览器 | 说明「当前浏览器不支持本地图片存储」，仅禁用图片项 |
| 图片已失效 | 清理过浏览器数据 | 自动回退主题背景 |

## 7. 已知限制与后续

| 项 | 现状 | 后续 |
| --- | --- | --- |
| 首屏闪一下默认色 | 主题在客户端挂载后才写入 `<html>` | 可在 `<head>` 内联脚本按 localStorage 预置 `data-theme` |
