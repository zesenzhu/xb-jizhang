# 分类图标选择

本文定义第五期分类图标在记账面板、分类管理、账单列表和统计页面中的展示与编辑规则。跨页面的总方案、缓存、测试和实施顺序见[第五期前端实施设计](./第五期前端实施设计.md)。分类图标必须通过统一渲染器展示，页面不能根据分类名称自行猜测图标。

## 1. 统一图标渲染器

渲染器输入：

```text
{
  iconSource: 'NONE' | 'LIBRARY' | 'IMAGE'
  iconKey: string | null
  iconAssetId: string | null
  iconUrl: string | null
  iconUrlExpiresAt: string | null
  color: string | null
  name: string
}
```

降级顺序固定为：

1. `IMAGE` 且图片加载成功，显示图片；
2. `LIBRARY` 且 `iconKey` 在前端白名单中，显示 Tabler 图标；
3. 使用 `color` 背景和分类名称首字；
4. 使用固定默认图标和中性颜色。

图标容器必须有稳定的宽高和 `shrink-0`，图片使用等比裁切。图片加载失败时保留分类名称和点击区域，不显示破损图片图标。

## 2. 页面使用位置

同一个分类在以下位置使用同一份图标数据：

| 页面 | 展示方式 | 交互 |
| --- | --- | --- |
| 记账抽屉 | 图标 + 分类名称 | 选择分类 |
| 账单列表 | 固定尺寸图标 | 查看账单 |
| 分类管理 | 图标预览 | Owner 编辑 |
| 统计分类列表 | 图标 + 名称 + 金额 | 分类下钻 |
| 统计 Tooltip | 图标 + 名称 + 精确金额 | 分类下钻 |

分类图标资源属于账本，不属于当前成员。共享账本成员刷新后必须看到同一个分类图标。

## 3. 分类编辑流程

### 3.1 打开编辑

- Owner 在分类管理中打开新增或编辑面板；
- 当前分类图标作为预选值；
- 系统默认分类显示“恢复默认”入口；
- Editor 和 Viewer 不显示编辑入口；
- 打开面板时复制表单状态，未保存选择不直接修改缓存中的分类。

### 3.2 图标库选择

图标库面板包含：

```text
搜索框
分组或类型筛选
图标网格
当前选中状态
预览区域
```

搜索匹配中文名称、英文别名和分组。图标键来自后端白名单，前端通过稳定映射表渲染 Tabler 组件。选择图标后只更新临时表单，点击保存才调用分类接口。

### 3.3 图片上传

支持 PNG、JPEG、WebP，单张不超过 2 MB。前端流程必须完整执行：

```text
选择文件
  -> 客户端检查大小和 MIME
  -> POST 创建上传会话
  -> PUT uploadUrl 上传文件
  -> POST complete 完成确认
  -> 保存分类并提交 iconAssetId
```

浏览器必须使用后端返回的 `requiredHeaders`，不能自行拼接 OSS 地址或对象键。上传进度、失败和重试状态显示在编辑面板内。

图片上传完成但分类保存失败时，前端保留表单内容并允许重试；服务端通过未绑定资源清理任务回收资源。关闭编辑面板时清理本地临时预览，不把临时 URL 写入持久化状态。

### 3.4 恢复默认

点击“恢复默认”后：

- 立即更新临时预览；
- 不立即提交服务器；
- 已上传但尚未绑定的临时图片从表单中移除；
- 点击保存时调用恢复默认接口或提交系统默认图标字段；
- 保存失败时保留恢复后的表单状态。

## 4. 状态矩阵

| 状态 | 页面行为 |
| --- | --- |
| 图标库加载中 | 固定尺寸骨架，不改变网格布局 |
| 图标库加载失败 | 保留当前图标，显示重试入口 |
| 图片本地预览 | 使用固定正方形容器裁切 |
| 图片上传中 | 显示进度，禁用重复提交 |
| 图片上传失败 | 保留名称、层级和排序，显示重试 |
| 完成确认失败 | 图片不可绑定，保留编辑内容 |
| 分类保存失败 | 面板不关闭，保留图标选择 |
| 图片加载失败 | 降级为颜色和首字 |
| 当前离线 | 图标库可预览；图片上传和分类保存不可执行 |
| 无权限 | 不显示编辑入口；接口错误统一提示 |
| 切换账本 | 清理当前未保存选择和旧账本图标缓存 |

## 5. 缓存与读取地址

- 图标库使用 React Query 缓存，按版本或查询关键词区分缓存键；
- 分类列表缓存保存图标描述和短期 `iconUrl`，不保存永久地址；
- `iconUrlExpiresAt` 到期前可以继续显示，过期后重新调用读取地址接口；
- 账本切换时清理旧账本分类图标数据，防止短暂显示上一个账本的图片；
- 图片加载失败只影响当前图标，不使分类列表或统计模块整体失败。

## 6. 可访问性

- 图标不能作为唯一信息，按钮必须同时包含分类名称或可访问名称；
- 图标库网格使用按钮语义，支持 Tab、方向键或连续 Tab 聚焦；
- 当前选中图标提供 `aria-pressed=true`；
- 上传按钮关联隐藏文件输入，明确接受 `image/png,image/jpeg,image/webp`；
- 图片加载失败的降级元素仍有分类名称；
- 颜色不能作为唯一状态表达，选中和错误状态同时使用文字、边框或图标。

## 7. 验收清单

- [ ] 新建账本的默认分类都有稳定图标；
- [ ] 记账、账单、分类管理和统计使用同一图标语义；
- [ ] Owner 可以搜索、选择、恢复默认和上传图片；
- [ ] 上传流程包含后端会话、OSS/MinIO PUT 和完成确认；
- [ ] 超过 2 MB、类型不允许或文件头不匹配时不能绑定分类；
- [ ] Editor/Viewer 看不到图标编辑入口；
- [ ] 图片加载失败时布局稳定且分类名称仍可见；
- [ ] 共享成员刷新后看到同一个分类图标；
- [ ] 分类图标变更不改变分类 ID、历史账单关联和统计金额；
- [ ] 切换账本或离开页面后旧 Tooltip 和旧图片状态不会残留。
