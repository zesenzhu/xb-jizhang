# 账单页 `/user`

## 1. 页面结构与布局

```text
/user                              一级 Tab，保留底栏与 pb-24
├── LedgerTopBar                   账本名 · 月份切换 · 收支日历入口
├── SyncStatusBar                  离线提示（仅在离线时出现）
├── MonthSummaryCard               总支出 / 总收入 / 结余
├── BillSearchBar                  关键词搜索 + 筛选入口 + 生效条件胶囊
├── BillGroupList                  按账单日分组
│   └── BillDayCard                日期 + 星期 + 当日合计 + 折叠
│       └── BillRow                图标 · 分类 · 时间·标题 · 金额
├── BillListFooter                 加载更多 / 无更多
└── CreateBillFab                  右下角悬浮入口（有权限时）
```

内容宽度 `max-w-md mx-auto`，横向内边距 `px-4`，底部预留 `pb-[calc(4rem+env(safe-area-inset-bottom))]`。

### 1.1 顶部账本栏

| 元素 | 行为 |
| --- | --- |
| 账本名 | 点击打开账本切换面板 |
| 左箭头 | 上一月，跨年时年份同步变化 |
| 右箭头 | 下一月，不允许超过当前月 |
| 月份文案 | `YYYY年M月` |
| 收支日历 | 一期渲染为禁用胶囊，点击提示「即将上线」 |

账本只有 1 个时仍显示名称（需求 5.1）。

### 1.2 概览卡

```text
总支出 ¥170.32                    ← 主视觉 font-black
总收入 ¥0.00    月结余 -¥170.32    ← 标签 text-white/60 + 数值白色
```

数值全部来自当前筛选结果。处于筛选状态时右上角追加「筛选结果」胶囊。为 0 时显示 `¥0.00`，不用占位符。

### 1.3 日期分组卡

```text
11/02 星期一                              支出: ¥45.70  ⌄
┌─────────────────────────────────────────────────┐
│ [餐饮] 餐饮                                     -¥16.80 │
│        22:20 · 晚饭                                     │
├─────────────────────────────────────────────────┤
│ [餐饮] 餐饮                                     -¥20.00 │
│        12:14 · 猪脚饭                                   │
└─────────────────────────────────────────────────┘
```

- 日期：当年显示 `MM/DD`，跨年追加年份；今天/昨天加前缀。
- 当日合计：点击折叠/展开，默认展开；同时有收支时显示「支出: ¥x  收入: ¥y」。
- 账单行：分类圆形图标 + 分类名 + `HH:mm · 标题或备注` + 右对齐金额。
- 标题与备注都为空时只显示时间，不显示占位文案。

## 2. 数据来源

| 用途 | 接口 | 缓存键 |
| --- | --- | --- |
| 账本信息 | `GET /ledgers/:id` | `['ledgers','detail',id]` |
| 账本列表（切换面板） | `GET /ledgers` | `['ledgers','list',{}]` |
| 账单列表 | `GET /ledgers/:id/transactions` | `['ledger',id,'transactions',normalized]` |
| 收支概览 | `GET /ledgers/:id/statistics/overview` | `['ledger',id,'statistics','overview',normalized]` |

**缓存键首段必须是 `'ledger'`**：`UserWorkspaceProvider` 在退出登录时按首段 `'user' | 'ledgers' | 'ledger'` 清理缓存，换成其他首段会残留上一个用户的账单。

### 2.1 查询参数

```text
page, pageSize=30,
from = 账本时区当月 1 日 00:00:00,
to   = 账本时区次月 1 日 00:00:00,   // 后端 to 为左闭右开 lt
type, categoryId, keyword, createdById   // 可选，来自筛选
```

`normalizeFilter` 需剔除 `undefined` 字段并按固定顺序序列化，否则键不稳定、缓存永不命中。

### 2.2 分页

`useInfiniteQuery`，`initialPageParam=1`，`getNextPageParam: last.hasNextPage ? last.page + 1 : undefined`。底部用 `IntersectionObserver` 触发下一页。

切换月份、账本或筛选条件时重置为第 1 页并回到顶部。

### 2.3 时区与日期分组

后端无 `timezone` 字段（缺口 B3），一期前端固定 `Asia/Shanghai`，常量集中在 `lib/bill/timezone.ts`，后端补齐后改为读 `ledger.timezone`。

```text
billDateOf(iso, tz) →
  Intl.DateTimeFormat('en-CA', { timeZone: tz, year, month, day })  → YYYY-MM-DD
```

不用 `Date.prototype.getDate()`，它按设备时区计算，跨时区用户会看到不同分组。

分组算法放 `lib/bill/bill-group.ts`：

```text
1. 按 billDateOf(occurredAt) 分桶
2. 桶内按 occurredAt 降序
3. 桶按 billDate 降序
4. 桶内分别累加 EXPENSE / INCOME 的 amountCents
```

### 2.4 概览统计

使用服务端聚合接口，**不在前端累加**：

```text
GET /ledgers/:id/statistics/overview?from=&to=&type=&categoryId=&accountId=
缓存键 ['ledger', id, 'statistics', 'overview', normalized]
staleTime 30s（与列表一致）
```

响应：

```text
{ from, to, totalIncomeCents, totalExpenseCents, netCents, transactionCount }
```

`docs/api/统计接口.md` 规定「服务端聚合结果为唯一口径，前端不重复计算」。概览卡三个数值直接取 `totalExpenseCents`、`totalIncomeCents`、`netCents`。

统计接口自带可见性规则：无账户账单计入、私人账户仅所有者可见、软删除与遗留 `TRANSFER` 排除。前端不做二次过滤。

#### 筛选参数不一致的处理

统计接口不支持 `keyword` 与 `payerId`（见索引「概览与列表筛选不一致」）。一期处理：

- 仅用 `from`/`to`/`type`/`categoryId`/`accountId` 时，概览与列表口径一致，正常展示。
- 存在 `keyword` 或 `payerId` 时，概览卡显示一行标注「概览未包含关键词/付款人条件」。

不静默展示与列表不一致的数字。

### 2.5 权限

`memberRole` 来自 `getLedger` 返回值：

| 角色 | FAB |
| --- | --- |
| `OWNER` / `EDITOR` | 显示 |
| `VIEWER` | 隐藏；空态引导改为「联系账本所有者」 |

## 3. 交互规则

| 场景 | 行为 |
| --- | --- |
| 搜索 | 输入不触发请求；键盘确认或点搜索图标才提交。清空关键词恢复其他筛选下的完整结果 |
| 筛选入口 | 打开筛选面板；「应用」后关闭并刷新列表、概览、条件胶囊；「取消」放弃变更 |
| 条件胶囊 | 每项可单独移除，末尾固定「清除全部」 |
| 切换月份 | 重置到第 1 页、回到顶部、概览与列表同步刷新 |
| 切换账本 | 筛选条件整体重置为默认当月 + 全部类型/分类/成员（需求 5.5） |
| 点击账单行 | 打开账单详情浮层 |
| 点击 FAB | 打开记账抽屉 |
| 下拉刷新 | 一期不做，刷新依赖重新进入或切换月份 |

## 4. 状态矩阵

| 状态 | 触发条件 | 呈现 |
| --- | --- | --- |
| 首次加载 | 无缓存且请求中 | 概览卡骨架 + 3 组日期卡骨架 |
| 有数据 | `items.length > 0` | 正常渲染 |
| 空账本 | `total === 0` 且无筛选 | 「还没有账单」+ 说明 + 有权限时引导点 FAB |
| 筛选无结果 | `total === 0` 且有筛选 | 「没有符合条件的账单」+ 清除筛选，保留输入 |
| 加载失败 | 请求错误且无缓存 | 错误文案 + 重试，保留顶部筛选条件 |
| 分页失败 | 后续页错误 | 列表底部「加载失败，点击重试」，已有数据不清空 |
| 无创建权限 | `VIEWER` | 不渲染 FAB |
| 离线 | `navigator.onLine === false` | 顶部提示条「当前离线，无法查看最新账单」 |
