# 分类选择

记账抽屉内的二级浮层，用于选择收入或支出分类。

## 1. 页面结构与布局

```text
✕                     交通                      ⊞
─────────────────────────────────────────────
[🚌] 交通                                    ›
[🚕] 交通-打车                                ›
[🚇] 交通-地铁                                ›
[🚖] 交通-火车                                ›
```

`layer='nested'`（`z-60`），叠加在记账抽屉之上，高度约视口 70%。

- 顶部：关闭、当前一级分类名、`⊞` 切换到一级分类总览。
- 列表：当前一级分类下的二级分类；一级分类自身始终在首行且可选。

一期默认进入「一级分类总览」（九宫格），点击某个有二级的一级分类后进入上图的分组列表。

### 1.1 一级总览态

```text
✕                    选择分类
─────────────────────────────────────────────
[🍜] 餐饮     [🛒] 购物    [👕] 服饰
[🧴] 日用     [📱] 数码    [💄] 美妆
[🏠] 住房     [🚌] 交通    [🎮] 娱乐
...
```

5 列九宫格，每格：圆形图标 + 名称。有二级的分类在图标右下角显示小圆点标记。

## 2. 数据来源

```text
GET /ledgers/:id/categories?type=<EXPENSE|INCOME>&pageSize=100
缓存键 ['ledger', id, 'categories']
staleTime 5min
```

仅返回启用分类（后端 `isActive` 过滤）。停用分类不出现，历史账单仍展示原分类。

### 2.1 层级结构（依赖 B1）

后端 `Category` 目前无 `parentId`（缺口 B1），一期无法实现两级。**降级方案**：全部按一级分类渲染，进入二级列表时为空。

B1 修复后按以下规则构建：

```text
CategoryTree {
  id, name, icon?, parentId,
  children: CategoryTree[]   // 仅两级
}

buildTree(categories) →
  1. parentId === null → 一级
  2. 按 parentId 挂到对应一级下
  3. 一级按 sortOrder 升序
  4. 丢弃 parentId 指向不存在的分类（防御脏数据）
```

### 2.2 结构假设的降级

为避免 B1 修复后大改，`buildTree` 在字段缺失时把扁平列表包装成「全部一级、无子级」。后端加 `parentId` 后仅此函数改动。

## 3. 交互规则

| 场景 | 行为 |
| --- | --- |
| 点击一级分类（无二级） | 选中并关闭浮层，抽屉分类字段显示该名称 |
| 点击一级分类（有二级） | 进入该分类的分组列表，**不选中** |
| 分组列表首行（一级自身） | 选中一级分类，账单只关联一级，不自动猜测二级 |
| 点击二级分类 | 选中并关闭浮层，抽屉显示 `一级-二级` |
| 点击 ✕ | 关闭浮层，抽屉分类保持原值 |
| 点击 ⊞ | 从分组列表返回一级总览 |
| 切换抽屉的支出/收入 | 关闭浮层，分类清空，重新进入时按新类型加载 |

需求 7.5 明确：直接选择一级分类时不自动选择二级；分类没有子分类时点击即完成选择。

## 4. 状态矩阵

| 状态 | 触发 | 呈现 |
| --- | --- | --- |
| 加载中 | 分类请求中 | 10 个骨架格 |
| 有数据 | `categories.length > 0` | 九宫格 / 分组列表 |
| 空分类 | `length === 0` | 「暂无可用分类」+ 说明（一期无分类管理入口） |
| 加载失败 | 请求错误 | 错误文案 + 重试按钮 |
| 当前已选 | 抽屉已选分类 | 对应格子高亮描边 + 主题色底 |

### 待建纯函数

`lib/bill/category-tree.ts`：`buildTree(categories) → CategoryTree[]`，配套单测覆盖扁平列表、两级嵌套、脏 `parentId`。

### 分类图标降级（依赖 D3）

后端 `transactionSelect` 与分类列表均未返回 `icon` / `color`。降级方案：

```text
CategoryIcon({ name, icon?, color? }) →
  icon 存在 → 渲染对应 lucide 图标
  icon 缺失 → 圆形底 + name 首字
  color 缺失 → 按 name 的哈希从固定色板取一色
```

色板固定 8 色，均取自 `globals.css` 语义 token 的邻近色，避免新增未定义变量。
