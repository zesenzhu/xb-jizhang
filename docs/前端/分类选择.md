# 分类选择

> **已并入记账主面板。** 分类选择器现在是 `components/bill/CategoryGrid.tsx`，
> 渲染在记账面板中部的滚动区里，不再是独立浮层。本文档仅保留层级、图标降级与
> 验收标准作为行为契约；页面结构以《记账抽屉》为准。

## 1. 页面结构与布局

```text
✕                     交通                      ⊞
─────────────────────────────────────────────
[🚌] 交通                                    ›
[🚕] 交通-打车                                ›
[🚇] 交通-地铁                                ›
[🚖] 交通-火车                                ›
```

`layer='nested'`（`z-60`），叠加在记账抽屉之上，高度约视口 70%。

- 顶部：关闭、当前一级分类名、`⊞` 切换到一级分类总览。
- 列表：当前一级分类下的二级分类；一级分类自身始终在首行且可选。

一期默认进入「一级分类总览」（九宫格），点击某个有二级的一级分类后进入上图的分组列表。

### 1.1 一级总览态

```text
✕                    选择分类
─────────────────────────────────────────────
[🍜] 餐饮     [🛒] 购物    [👕] 服饰
[🧴] 日用     [📱] 数码    [💄] 美妆
[🏠] 住房     [🚌] 交通    [🎮] 娱乐
...
```

5 列九宫格，每格：圆形图标 + 名称。有二级的分类在图标右下角显示小圆点标记。

## 2. 数据来源

```text
GET /ledgers/:id/categories?type=<EXPENSE|INCOME>&pageSize=100
缓存键 ['ledger', id, 'categories']
staleTime 5min
```

仅返回启用分类（后端 `isActive` 过滤）。停用分类不出现，历史账单仍展示原分类。

### 2.1 层级结构

```text
CategoryTree {
  id, name, icon?, parentId,
  children: CategoryTree[]   // 仅两级
}

buildTree(categories) →
  1. parentId === null → 一级
  2. 按 parentId 挂到对应一级下
  3. 一级按 sortOrder 升序
  4. 丢弃 parentId 指向不存在的分类（防御脏数据）
```

服务端正式返回 `parentId`。前端对缺失父级、循环或三级脏数据做防御性提升，正常数据始终按最多两级渲染。

## 3. 交互规则

| 场景 | 行为 |
| --- | --- |
| 点击一级分类（无二级） | 选中并关闭浮层，抽屉分类字段显示该名称 |
| 点击一级分类（有二级） | 在九宫格下方就地展开分组列表，**不选中**；再次点击收起 |
| 分组列表首行（一级自身） | 选中一级分类，账单只关联一级，不自动猜测二级 |
| 点击二级分类 | 选中并关闭浮层；**九宫格里该格改为显示这个二级分类**，抽屉显示 `一级-二级` |

一级和二级都是「分类项」：选中二级后，如果九宫格仍显示一级，
用户会以为没选上。`resolveGridTile` 负责把某格解析成「当前应显示哪个分类」，
同时决定是否保留子级角标（选中二级后角标消失，因为已在二级层）。
| 再次点击已展开的一级分类 | 收起分组列表，选择不变 |
| 切换抽屉的支出/收入 | 关闭浮层，分类清空，重新进入时按新类型加载 |

需求 7.5 明确：直接选择一级分类时不自动选择二级；分类没有子分类时点击即完成选择。

## 4. 状态矩阵

| 状态 | 触发 | 呈现 |
| --- | --- | --- |
| 加载中 | 分类请求中 | 10 个骨架格 |
| 有数据 | `categories.length > 0` | 九宫格 / 分组列表 |
| 空分类 | `length === 0` | 「暂无可用分类」+ 说明（一期无分类管理入口） |
| 加载失败 | 请求错误 | 错误文案 + 重试按钮 |
| 当前已选 | 抽屉已选分类 | 对应格子高亮描边 + 主题色底 |

## 5. 组件清单

### 复用

`BottomSheet`（`layer='nested'`）、`Skeleton`。

### 新建

| 组件 | 路径 | 状态 |
| --- | --- | --- |
| `CategoryGrid` | `components/bill/CategoryGrid.tsx` | 五列九宫格；有子级时下方就地展开列表 |
| `CategoryIcon` | `components/bill/CategoryIcon.tsx` | 已实现 |

### 纯函数

`lib/bill/category-tree.ts`：`buildCategoryTree(categories) → CategoryNode[]`，配套 `test/category-tree.test.ts` 覆盖扁平列表、两级嵌套、脏 `parentId`、非法三级提升、排序与 `categoryPathText`。

### 分类图标展示契约

第五期接入后，分类列表和统计分类项统一返回 `iconSource`、`iconKey`、`iconAssetId`、`iconUrl`、`iconUrlExpiresAt` 和 `color`。在接口尚未联调完成前，`CategoryIcon` 继续使用名称首字 + 哈希色板兜底。

```text
CategoryIcon({ name, iconSource, iconKey, iconAssetId, iconUrl, color }) →
  IMAGE 且图片可读 → 显示图片
  LIBRARY 且 iconKey 在受控映射表 → 显示 Tabler 图标
  其他情况 → 颜色背景 + name 首字
```

色板固定 8 色，均取自 `globals.css` 语义 token 的邻近色，避免新增未定义变量。
