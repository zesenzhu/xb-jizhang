# 成员与邀请 `/user/ledgers/:ledgerId/members`

共享账本的成员列表、角色管理与邀请。个人账本不进入本页。

## 1. 页面结构与布局

```text
┌────────────────────────────────────────┐
│ ‹          成员与邀请        邀请成员   │
├────────────────────────────────────────┤
│ 家庭账本 · 4 位成员                     │
├────────────────────────────────────────┤
│ 👤 我              OWNER        本人    │
│ 👤 周宁            EDITOR         ⋯    │
│ 👤 吴桐            VIEWER         ⋯    │
├────────────────────────────────────────┤
│ 待处理邀请                              │
│ ming@example.com  EDITOR  11月7日到期   │
│                                撤销     │
│                                        │
│ 转移账本 Owner                      ›   │
└────────────────────────────────────────┘
```

- 顶栏右侧「邀请成员」仅 `OWNER` 可见。
- 自己的行不显示 `⋯`，改为「本人」标记。
- 待处理邀请区仅 `OWNER` 可见。
- 「转移账本 Owner」仅 `OWNER` 且成员数 > 1 时显示。

## 2. 数据来源

| 用途 | 接口 | 缓存键 | staleTime |
| --- | --- | --- | --- |
| 成员列表 | `GET /ledgers/:id/members` | `['ledger',id,'members']` | 5min |
| 待处理邀请 | `GET /ledgers/:id/invitations` | `['ledger',id,'invitations']` | 30s |
| 发起邀请 | `POST /ledgers/:id/invitations` | 成功后失效 invitations | — |
| 撤销邀请 | `DELETE /ledgers/:id/invitations/:iid` | 同上 | — |
| 改角色 | `PATCH /ledgers/:id/members/:mid/role` | 成功后失效 members + `ledgers` | — |
| 移除成员 | `DELETE /ledgers/:id/members/:mid` | 同上 | — |
| 主动退出 | `POST /ledgers/:id/members/leave` | 失效 members + preferences | — |
| 转移 Owner | `POST /ledgers/:id/ownership-transfer` | 失效 members + `ledgers` | — |

**改角色/移除/转移后必须同时失效 `['ledgers']`**：`memberRole` 与 `memberCount` 在账本摘要里，不失效会让「我的账本」显示过期角色。

### 2.1 权限矩阵

| 操作 | `OWNER` | `EDITOR` | `VIEWER` |
| --- | --- | --- | --- |
| 查看成员列表 | ✅ | ✅ | ✅ |
| 查看待处理邀请 | ✅ | ❌ | ❌ |
| 发起/撤销邀请 | ✅ | ❌ | ❌ |
| 改角色 / 移除成员 | ✅ | ❌ | ❌ |
| 转移 Owner | ✅ | ❌ | ❌ |
| 主动退出 | 需先转移 | ✅ | ✅ |

## 3. 交互规则

### 3.1 邀请成员

| 字段 | 规则 |
| --- | --- |
| 邮箱 | 必填，格式校验，服务端会规范化 |
| 角色 | 只能 `EDITOR` 或 `VIEWER`；**不提供 `OWNER` 选项** |

有效期固定 72 小时，由服务端决定。创建成功后：

- 显示目标邮箱、角色、到期时间
- 提供「复制邀请链接」（链接含一次性 Token，仅此一次可见）
- 不显示 Token 哈希

需求 8.1 明确“邀请角色只能选择 EDITOR 或 VIEWER，不能通过邀请授予 OWNER”。

### 3.2 成员操作

| 操作 | 前置校验 |
| --- | --- |
| 改角色 | 目标不是唯一 Owner；不能直接把 Owner 降级，需走转移 |
| 移除成员 | 目标不是自己；目标不是唯一 Owner |
| 转移 Owner | 目标是活跃成员；转移后原 Owner 降为 `EDITOR` |
| 主动退出 | 不是最后一本可访问账本；本人不是唯一 Owner |

任何会导致「账本没有 Owner」的操作，前端禁用按钮并说明原因；服务端返回 `40902` 时提示「账本必须至少保留一名 Owner」。

### 3.3 错误映射

| code | 文案 |
| --- | --- |
| `40301` | 当前角色没有该操作权限 |
| `40901` | 该邮箱已有待处理邀请 |
| `40902` | 账本必须至少保留一名 Owner / 成员状态已变化 |
| `40903` | 个人账本不能邀请成员 |
| `40401` | 成员不存在或已不在本账本 |

## 4. 状态矩阵

| 状态 | 触发 | 呈现 |
| --- | --- | --- |
| 加载中 | 请求中 | 成员行骨架 ×4 |
| 空成员 | 只有自己 | 成员区仅自己 + 邀请引导 |
| 无待处理邀请 | `items.length === 0` | 「暂无待处理邀请」+ 邀请按钮 |
| 邀请中 | POST 进行中 | 邀请键 loading |
| 邀请成功 | 201 | 展示链接 + 复制按钮，只显示一次 |
| 邀请失败 | 错误 | 表单内错误条，保留输入 |
| 操作中 | PATCH/DELETE 进行中 | 对应行禁用 |
