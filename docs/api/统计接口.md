# 小宝记账统计接口

## 1. 公共约定

统计接口使用普通用户会话和 `/api` 前缀。调用者必须是目标账本的活跃成员，`OWNER`、`EDITOR` 和 `VIEWER` 均可查询。统计金额使用整数分，服务端聚合结果为唯一口径，前端不重复计算。

一期只统计 `EXPENSE` 和 `INCOME`，不接收或处理 `TRANSFER`。

## 2. 接口总览

| 方法 | 路径 | 权限 | 用途 |
| --- | --- | --- | --- |
| `GET` | `/api/ledgers/:ledgerId/statistics/overview` | `VIEWER+` | 查询收入、支出、净收支和账单数量 |

## 3. 查询统计概览

### 3.1 请求

```text
GET /api/ledgers/:ledgerId/statistics/overview?from=2026-10-01T00:00:00.000Z&to=2026-11-01T00:00:00.000Z&type=EXPENSE&categoryId=uuid&accountId=uuid&payerId=uuid&keyword=早餐
```

查询参数：

| 参数 | 必填 | 说明 |
| --- | --- | --- |
| `from` | 否 | ISO 8601 起始时间，包含该时间 |
| `to` | 否 | ISO 8601 结束时间，不包含该时间 |
| `type` | 否 | `EXPENSE` 或 `INCOME` |
| `categoryId` | 否 | 当前账本分类 ID |
| `accountId` | 否 | 当前账本账户 ID |
| `payerId` | 否 | 当前账本活跃成员 ID |
| `keyword` | 否 | 标题或备注关键词，服务端会去除首尾空格并执行不区分大小写的包含匹配 |

`from` 和 `to` 均省略时查询全部历史数据；如果同时填写，`from` 必须早于 `to`。日期格式非法或范围无效时返回 `40021`。

### 3.2 统计规则

- 只统计当前账本内 `deletedAt IS NULL` 的账单。
- 无账户账单仍参与收入、支出和净收支统计。
- 共享账户关联账单对所有活跃成员可见。
- 私人账户关联账单仅对账户所有者可见，其他成员不会将其计入统计。
- 指定 `accountId` 时只统计该账户关联的账单，不包含无账户账单。
- 指定 `payerId` 时只统计该实际付款人关联的账单。
- 指定 `keyword` 时匹配账单标题或备注，匹配规则与账单列表一致。
- 一期不处理数据库中遗留的 `TRANSFER` 记录。
- `netCents = totalIncomeCents - totalExpenseCents`。

### 3.3 成功响应

```json
{
  "from": "2026-10-01T00:00:00.000Z",
  "to": "2026-11-01T00:00:00.000Z",
  "totalIncomeCents": 10000,
  "totalExpenseCents": 3500,
  "netCents": 6500,
  "transactionCount": 3
}
```

没有符合条件的账单时，四个数值字段均返回 `0`；`from`、`to` 未传时返回 `null`。

## 4. 错误约定

| HTTP | code | 场景 |
| --- | --- | --- |
| `400` | `40021` | 日期范围或查询参数非法 |
| `404` | `40421` | 账本不存在、成员不存在或成员不是 `ACTIVE` |

账单、账户和私人账户的存在性不能通过统计错误响应泄露给无权用户。

## 5. 测试要求

- Service 测试覆盖收入、支出、净收支、空结果、日期范围、类型筛选、付款人、关键词和软删除过滤条件。
- 覆盖无账户账单参与统计、私人账户可见性和遗留 `TRANSFER` 不计入统计。
- Controller 测试覆盖当前用户、账本路径和查询参数传递。
- 后续增加月度趋势、分类排行或成员统计时，必须复用本接口的账本、软删除和私人账户可见性规则。

## 6. 当前实现验证

- 已实现 `GET /api/ledgers/:ledgerId/statistics/overview`。
- 已使用 Prisma `groupBy` 按账单类型聚合，未引入前端计算或新的数据库结构。
- 统计 Service/Controller 测试已覆盖主要成功、空数据、非法输入和成员隔离场景。
