# 小宝记账分类图标接口

## 1. 公共约定

所有接口使用 `/api` 前缀和普通用户会话。账本资源先校验当前用户的 `LedgerMember(status=ACTIVE)`，再执行分类或资源权限校验。统一响应、错误、时间、UUID、幂等和敏感字段规则遵循[接口约定](./接口约定.md)。

本接口文档是第五期设计稿，状态为 `review`，接口路径和字段在实现前需与 DTO、Prisma Migration 和前端调用一起确认。

## 2. 图标来源模型

### 2.1 分类响应字段

分类列表、分类新增/编辑响应和统计分类项统一返回：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `iconSource` | `NONE \| LIBRARY \| IMAGE` | 图标来源 |
| `iconKey` | `string \| null` | 图标库稳定键；只有 `LIBRARY` 时有值 |
| `iconAssetId` | `uuid \| null` | 分类图片资源 ID；只有 `IMAGE` 时有值 |
| `iconUrl` | `string \| null` | 图片短期读取地址；非 `IMAGE` 时为空 |
| `iconUrlExpiresAt` | `ISO 8601 \| null` | 图片读取地址过期时间 |
| `color` | `string \| null` | 分类颜色，建议使用 `#RRGGBB` |

服务端拒绝字段组合不一致的请求，不根据客户端字段猜测优先级。`iconUrl` 和 `iconUrlExpiresAt` 不能写入分类请求，也不能保存到数据库。

### 2.2 图标来源约束

| `iconSource` | 必填字段 | 禁止字段 |
| --- | --- | --- |
| `NONE` | 无 | `iconKey`、`iconAssetId` |
| `LIBRARY` | 合法 `iconKey` | `iconAssetId` |
| `IMAGE` | 当前账本下已确认的 `iconAssetId` | `iconKey` |

## 3. 接口总览

| 方法 | 路径 | 权限 | 用途 |
| --- | --- | --- | --- |
| `GET` | `/api/ledgers/:ledgerId/category-icons/library` | `VIEWER+` | 查询受控图标库 |
| `POST` | `/api/ledgers/:ledgerId/category-icon-assets/upload-sessions` | `OWNER` | 创建图片上传会话 |
| `POST` | `/api/ledgers/:ledgerId/category-icon-assets/:assetId/complete` | `OWNER` | 校验对象并完成上传 |
| `GET` | `/api/ledgers/:ledgerId/category-icon-assets/:assetId/access-url` | `VIEWER+` | 获取短期图片读取地址 |
| `POST` | `/api/ledgers/:ledgerId/categories/:categoryId/restore-default-icon` | `OWNER` | 恢复系统默认图标和颜色 |

分类创建和编辑仍使用[账户与分类接口](./账户与分类接口.md)的路径，在请求 Body 中增加图标字段。

## 4. 查询图标库

请求：

```text
GET /api/ledgers/:ledgerId/category-icons/library?type=EXPENSE&q=餐饮&page=1&pageSize=40
```

查询参数：

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `type` | `EXPENSE \| INCOME` | 否 | 按分类类型过滤推荐图标 |
| `q` | `string` | 否 | 匹配中文名称、英文别名和分组 |
| `page` | `number` | 否 | 默认 `1` |
| `pageSize` | `number` | 否 | 默认 `40`，最大 `100` |

响应 `data`：

```json
{
  "items": [
    {
      "key": "tabler:tools-kitchen-2",
      "label": "餐具",
      "aliases": ["餐饮", "food", "kitchen"],
      "group": "餐饮",
      "defaultTypes": ["EXPENSE"]
    }
  ],
  "total": 1,
  "page": 1,
  "pageSize": 40,
  "hasNextPage": false
}
```

图标库只返回后端白名单中的稳定键。客户端不能根据返回值以外的字符串加载任意组件。

## 5. 创建图片上传会话

请求：

```http
POST /api/ledgers/ledger-uuid/category-icon-assets/upload-sessions
Content-Type: application/json
```

```json
{
  "clientRequestId": "uuid",
  "fileName": "category.png",
  "mimeType": "image/png",
  "sizeBytes": 18342
}
```

服务端规则：

- 当前用户必须是账本 `OWNER`；
- `sizeBytes` 必须大于 0 且不超过 `2 * 1024 * 1024`；
- `mimeType` 只接受 `image/png`、`image/jpeg`、`image/webp`；
- 文件名只用于元数据，不能影响对象键；
- 对象键由服务端生成，客户端不能指定目录、扩展名或资源 ID；
- 同一账本的 `clientRequestId` 重复提交返回已有资源结果；
- 资源创建后状态为 `PENDING`，未绑定分类时设置 `orphanExpiresAt`。

响应 `data`：

```json
{
  "assetId": "asset-uuid",
  "status": "PENDING",
  "uploadMethod": "PUT",
  "uploadUrl": "https://storage.example.com/signed-upload-url",
  "requiredHeaders": {
    "Content-Type": "image/png"
  },
  "expiresAt": "2026-11-10T08:10:00.000Z"
}
```

客户端必须使用响应中的 `uploadUrl`、`uploadMethod` 和 `requiredHeaders` 原样上传文件：

```ts
await fetch(uploadUrl, {
  method: 'PUT',
  headers: requiredHeaders,
  body: file,
});
```

上传成功不等于资源已经可用，客户端仍必须调用完成接口。

## 6. 完成上传

请求：

```text
POST /api/ledgers/:ledgerId/category-icon-assets/:assetId/complete
```

服务端执行：

1. 校验当前用户为 `OWNER`，资源属于当前账本且状态为 `PENDING`；
2. 校验上传会话未过期；
3. 对对象执行 `HEAD`，确认对象存在且实际大小不超过 2 MB；
4. 读取对象头部，确认真实格式为 JPEG、PNG 或 WebP；
5. 可选读取图片宽高并保存；
6. 事务更新资源为 `ATTACHED`，写入真实 MIME、大小和 `uploadedAt`；
7. 返回资源摘要和短期读取地址。

响应 `data`：

```json
{
  "assetId": "asset-uuid",
  "status": "ATTACHED",
  "mimeType": "image/png",
  "sizeBytes": 18342,
  "accessUrl": "https://storage.example.com/signed-read-url",
  "accessUrlExpiresAt": "2026-11-10T08:05:00.000Z"
}
```

对象不存在、大小超限或文件头不匹配时，资源保持不可读，响应错误并记录脱敏的 `lastUploadError`。

## 7. 获取图片读取地址

请求：

```text
GET /api/ledgers/:ledgerId/category-icon-assets/:assetId/access-url
```

服务端校验：

- 当前用户是账本活跃成员；
- 资源属于当前账本且状态为 `ATTACHED`；
- 资源被当前分类引用时，当前账本活跃成员可以读取；
- 资源已确认但尚未绑定分类时，只有上传者可以在 `orphanExpiresAt` 前预览；
- 不返回其他账本资源、已删除资源或永久公开地址。

响应：

```json
{
  "assetId": "asset-uuid",
  "accessUrl": "https://storage.example.com/signed-read-url",
  "accessUrlExpiresAt": "2026-11-10T08:05:00.000Z"
}
```

分类列表和统计分类响应可以直接带上短期 `iconUrl`，减少前端逐项请求。前端不得把该地址写入账单、分类或长期分享数据。

## 8. 分类创建与编辑扩展

分类新增请求增加：

```json
{
  "type": "EXPENSE",
  "name": "宠物",
  "parentId": null,
  "sortOrder": 110,
  "iconSource": "LIBRARY",
  "iconKey": "tabler:paw",
  "iconAssetId": null,
  "color": "#F97316"
}
```

分类图片请求示例：

```json
{
  "name": "宠物",
  "iconSource": "IMAGE",
  "iconKey": null,
  "iconAssetId": "asset-uuid",
  "color": "#F97316"
}
```

服务端还必须校验原有分类规则：Owner 权限、分类类型、父级、两级层级、名称唯一、排序和停用状态。Editor/Viewer 直接访问新增、编辑、恢复和上传接口时返回统一权限错误。

替换图片时，旧资源在同一事务中解除当前引用并标记 `DELETED`，新资源成为当前引用；对象物理删除由清理任务异步执行。

## 9. 恢复默认图标

请求：

```text
POST /api/ledgers/:ledgerId/categories/:categoryId/restore-default-icon
```

仅允许 `isSystem=true` 且存在 `defaultKey` 的分类。成功后：

- `iconSource` 设置为 `LIBRARY`；
- `iconKey` 设置为该 `defaultKey` 对应的默认图标；
- `color` 设置为默认颜色；
- 分类名称、排序、父级和启用状态保持不变；
- 旧图片资源按替换流程标记为 `DELETED`。

自定义分类调用该接口返回 `40021` 或 `40421`，具体错误映射遵循接口约定。

## 10. 统计接口字段扩展

`GET /api/ledgers/:ledgerId/statistics/categories` 的每个分类项增加：

```json
{
  "categoryId": "category-uuid",
  "categoryRootId": "category-uuid",
  "parentId": null,
  "bucketType": "CATEGORY",
  "name": "餐饮",
  "iconSource": "LIBRARY",
  "iconKey": "tabler:tools-kitchen-2",
  "iconAssetId": null,
  "iconUrl": null,
  "iconUrlExpiresAt": null,
  "color": "#F97316",
  "amountCents": 124950,
  "percentage": 69.98,
  "transactionCount": 17,
  "drilldown": {
    "categoryRootId": "category-uuid",
    "from": "2026-11-01T00:00:00.000Z",
    "to": "2026-12-01T00:00:00.000Z",
    "type": "EXPENSE"
  }
}
```

服务端仍返回完整分类明细、金额、占比、账单数和原有下钻字段。统计图表最多展示 6～8 个分类和一个前端聚合的“其他”，不在服务端创建新的分类桶，也不改变账单下钻参数。

趋势接口不改变统计口径。现有 `expenseCents`、`incomeCents`、`netCents`、`transactionCount` 和 `drilldown` 已满足 Tooltip 所需数据，前端切换指标不应重复请求。

## 11. 错误码

| HTTP | code | 场景 |
| --- | --- | --- |
| `400` | `40021` | 图标来源组合、文件声明、颜色或默认恢复参数非法 |
| `401` | `40101` | 未登录或会话无效 |
| `403` | `40321` | 当前角色不能管理分类图标 |
| `404` | `40421` | 账本、分类或资源不可见 |
| `409` | `40921` | 分类更新冲突或资源已被绑定 |
| `409` | `40942` | 账本分类图标配额不足 |
| `415` | `41501` | 文件头不是 JPEG、PNG 或 WebP |
| `503` | `50341` | 对象存储不可用或分类图标功能关闭 |

错误响应遵循统一结构，不返回 AccessKey、Secret、完整对象键或内部存储错误。

## 12. 测试契约

- Controller 测试覆盖路径参数、认证上下文、DTO 字段传递和权限角色。
- Service 测试覆盖图标来源互斥、图标库白名单、默认恢复、跨账本资源、替换和幂等。
- Repository/Prisma 集成测试覆盖资源唯一约束、状态更新、分类绑定和清理索引。
- 对象存储契约测试覆盖 `PUT` 签名、`HEAD`、文件头读取、`GET` 签名和删除。
- HTTP 契约测试覆盖响应中的图标字段与统计字段一致性。
